## Порядок и почему

2026-11-19 (позже): пользователь выбрал сервер в сети как отличительную
«фишку» для продвижения в российских офисах — он идёт первым; подпись кода
ждёт. Ctrl+Win и выключенная озвучка сделаны и войдут в общий выпуск.

Порядок выбран пользователем 2026-11-19: озвучка → Ctrl+Win → сервер. Подпись кода добавлена в тот же день после исследования — перед сервером.

1. **Озвучка по умолчанию выключена** — самая маленькая и безопасная; улучшает
   первый запуск для всех новых пользователей: не предлагает сразу сотни МБ
   Silero и не показывает «Озвучить», пока озвучка не нужна. Только для новых
   установок; у обновляющихся ничего не меняется.
2. **Ctrl+Win** — ежедневное удобство пользователя; требует низкоуровневого
   хука клавиатуры и аккуратного обращения с клавишей Win.
3. **Подпись кода** — снимает главный барьер для новых пользователей (SmartScreen), но меняет процесс выпуска: сборка в CI и порядок подписей.
4. **Сервер в сети** — самая крупная и рискованная; начинать только после
   решения L1 по безопасности.
