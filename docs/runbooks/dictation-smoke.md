## Нативный smoke без микрофона

В отдельный `.scratch/stt-smoke-input` положить два закреплённых GGUF,
`runtime-0.2.3.tar.gz` и публичный `example.wav`, названные в runtime-инструкции.
Проверить хеши по `src-tauri/src/stt/local/catalog.rs`.

```powershell
$env:GLAGOL_LOCAL_SMOKE_ROOT = (Resolve-Path '.scratch/stt-smoke-input').Path
cargo test --manifest-path src-tauri/Cargo.toml native_gigaam_smoke -- --ignored --nocapture
```

Ожидается успешное распознавание обеими моделями дважды, без скачивания и
микрофона. Это не проверка хоткея, разрешений Windows или вставки текста.

## Пользовательский путь

1. В согласованной тестовой установке выбрать микрофон. Проверить разрешения
   Windows, mute и уровень входа. Не менять системные настройки молча.
2. Локальный режим: загрузить/выбрать CTC; проверить отмену/продолжение загрузки,
   затем повторить распознавание с RNNT. Наличие модели в памяти не доказывает
   корректность загрузчика.
3. Нажать хоткей: «Подготовка микрофона…» до первого пакета, затем сигнал записи
   и изменяющийся уровень. Произнести публичную фразу, отпустить, проверить вставку
   и режим «Только буфер обмена». Отпускание во время подготовки отменяет попытку.
4. Проверить тишину, недоступное устройство, смену микрофона и повторный запуск
   сессии после ошибки. Потеря первых слов оценивается после сигнала готовности.
5. Сервер организации: использовать согласованный тестовый сервер; проверить
   адрес/модель/ключ, сохранение отдельного профиля, распознавание и возврат
   в локальный режим. HTTP допускается только в рамках текущей private-IP/localhost
   политики; остальные адреса требуют HTTPS. Не отправлять речь на случайный сервис.
6. Облачный режим: только при доступном согласованном провайдере. Проверить
   независимость ключей и профилей; без доступа отметить NOT_RUN.
7. Повторить живую диктовку во время озвучки Silero. Сохранность текста и
   отзывчивость интерфейса проверять отдельно от замеров одного WAV.

В журнал писать сборку, выбранный режим/модель, устройство, ожидаемый/фактический
результат, ограничения. Не включать ключи или пользовательские расшифровки.
