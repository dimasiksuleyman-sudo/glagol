# Процедуры Глагола

Состояние задач — в [STATUS](../STATUS.md), правила — [AGENTS](../../AGENTS.md).
Эти документы описывают действия и критерии, не сообщают об их выполнении.

| Процедура | Когда использовать |
|---|---|
| [Windows build](windows-build.md) | Проверка кода, сборка EXE/NSIS и идентификация артефакта |
| [Silero](tts-smoke.md) | Runtime, модель, синтез, отмена и ручная оценка звука |
| [Диктовка](dictation-smoke.md) | GigaAM, микрофон, хоткей, сервер/облако |
| [Релиз](release.md) | Проверка обновления, подготовка и публикация конкретной сборки |

Рабочая папка команд — корень репозитория, если не указано иначе.
Записывать фактические версии инструментов, UTC-дату и решающую строку вывода.
PowerShell: после каждой native-команды проверять `$LASTEXITCODE`; не продолжать
после ошибки. Приведённые блоки — последовательность отдельных проверок.
Скачивание больших артефактов, запуск GUI, установка и публикация должны
соответствовать текущему заданию; наличие команды здесь не является разрешением.
