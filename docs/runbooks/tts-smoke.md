## Программная проверка

Нужны точный `v5_5_ru.pt` и 13 закреплённых архивов runtime. Проверить размеры и
SHA-256 по каталогу приложения; произвольный `.pt` не использовать. Инструкции
получения/сборки — в runtime-документе, модели не входят в обычный CI.

Подготовить отдельный каталог `.scratch/tts-smoke-input` с моделью и архивами
в корне; затем отдельными командами:

```powershell
$env:GLAGOL_TTS_SMOKE_ROOT = (Resolve-Path '.scratch/tts-smoke-input').Path
$env:GLAGOL_TTS_ASSEMBLE_SMOKE = '1'
cargo test --release --manifest-path src-tauri/Cargo.toml native_silero_pipeline_and_cancel -- --ignored --nocapture
```

Для Python-тестов использовать уже проверенный embedded runtime:

```powershell
& .scratch/silero/runtime-271/python.exe -I -B scripts/silero/test_assemble.py
& .scratch/silero/runtime-271/python.exe -I -B scripts/silero/test_worker.py
```

Зафиксировать test counts, время, версию/хеш модели и runtime. Тест Rust проверяет
сборку runtime при установленном флаге, запись нескольких фрагментов и отмену;
отдельно сверять текущую реализацию теста в worker.rs при её изменении.
Отсутствующие входы → NOT_RUN/BLOCKED, не PASS обычного cargo test.

## Ручной сценарий

1. Запустить согласованную тестовую установку. До включения Silero проверить,
   что нет автоматической загрузки/worker и независимая диктовка доступна.
2. Настройки → локальная озвучка: проверить текст условий, изначально снятое
   подтверждение и запрет установки без него.
3. Проверить автоматическую загрузку, прогресс, отмену/продолжение. Если endpoint
   недоступен, записать это отдельно; успешный импорт не закрывает загрузку.
4. Импортировать точную модель; неверный файл должен отклоняться. Проверить
   восстановление/удаление только тестовых компонентов.
5. Прослушать все пять голосов. Озвучить публичный текст с числами, датами,
   ударениями, вопросами и латиницей; записать замечания по произношению.
6. Озвучить длинный документ, проверить библиотеку, длительность, playback/export.
   Отменить активный синтез: готовой записи не появляется.
7. На тестовой библиотеке проверить сохранность legacy WAV после обновления
   и отсутствие runtime/consent/previews в бэкапе.
8. Проверить выгрузку worker после простоя и выход вместе с приложением.
   Crash/timeout/parent-death fault injection — отдельные результаты, если выполнялись.

Валидный WAV и распознавание ASR не заменяют прослушивание. Лицензия Silero
не распространяется автоматически на независимый STT. Записать результаты
программных и ручных проверок отдельно; у каждой назвать сборку/окружение.
