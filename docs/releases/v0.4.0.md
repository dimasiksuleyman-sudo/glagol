# Glagol 0.4.0 — локальная диктовка и озвучка / local dictation and TTS

## Русский

Глагол 0.4.0 для Windows 10/11 x64 объединяет локальную диктовку GigaAM,
офисный или облачный сервер распознавания и необязательную озвучку Silero.
Это следующий публичный выпуск после 0.2.1; изменения локальной 0.3.0 вошли сюда.

### Что нового с 0.2.1

- Локальная диктовка GigaAM v3 CTC/RNNT: модели и небольшой CPU-движок скачиваются
  из настроек отдельно. Доступны также независимые профили офисного сервера и облака.
- Подготовка микрофона перед сигналом начала записи и новая иконка с микрофоном.
- Озвучка Silero v5.5: пять русских голосов, прослушивание образцов, загрузка
  компонентов с прогрессом, отменой, продолжением и проверкой целостности.
- Новые озвучки сохраняются в локальную библиотеку и экспортируются в WAV.
  Старые записи и резервные копии сохраняют совместимость.
- Облачная озвучка SaluteSpeech, её ключ и счётчик квоты удалены.
  Ключи и настройки диктовки остаются отдельными.

### Установка и обновление

Скачайте **[Glagol_0.4.0_x64-setup.exe](https://github.com/dimasiksuleyman-sudo/glagol/releases/download/v0.4.0/Glagol_0.4.0_x64-setup.exe)** — 9 742 481 байт (9,29 МиБ).
Это тот же установщик, который прошёл ручной прогон на втором ПК с Windows 10.
Установщик не подписан: SmartScreen может показать предупреждение. Сверьте
источник и SHA-256; если доверяете файлу, «Подробнее» → «Выполнить в любом случае».

Перед обновлением 0.2.1 создайте резервную копию в настройках и завершите Глагол
через меню трея «Выход». Запустите установщик 0.4.0, выберите **«Не удалять»**
на экране существующей установки и прежнюю папку приложения. В проверенном
сценарии сохранились пять записей, воспроизведение, экспорт, настройки и ключ STT.

Silero устанавливается отдельно: модель **145,4 МБ**, движок **249,3 МБ**;
для установки освободите не менее **1,9 ГБ**. Системные Python и CUDA не нужны.
После загрузки синтез работает локально. **Silero — необязательный компонент
для некоммерческого использования, CC BY-NC-SA 4.0**; приложение — MIT.
Для диктовки, в том числе через офисный сервер, Silero не нужна.
Условия моделей и STT-провайдеров действуют отдельно. Yandex SpeechKit пока не включён.

### Проверено и что осталось

Ручной прогон 13 сентября 2026: Windows 10 Pro 22H2 x64, AMD FX-8300, 16 ГБ.
Подтверждены чистая установка, обновление 0.2.1→0.4.0, восстановление библиотеки
с автоматической резервной копией, сохранение прежних записей и STT-настроек,
проверка существующего ключа, скачивание/отмена/продолжение установки Silero,
все пять голосов, короткий текст с числами и латиницей, библиотека и внешний WAV-плеер.

**Ручная QA приостановлена, не объявлена завершённой.** На этом ПК ещё не проверены
длинный синтез и его отмена, импорт/восстановление/удаление компонентов, выгрузка
процесса после простоя/выхода, живая диктовка после обновления и её совместная
работа с TTS. Crash/timeout/parent-death отдельно не проверялись. 0.3.0→0.4.0
исключён из прогона: 0.3.0 не публиковалась. Программные результаты предыдущего
дня приведены отдельно в журнале и не заменяют эти ручные проверки.

## English

Glagol 0.4.0 for Windows 10/11 x64 brings local GigaAM dictation, independent
office/cloud recognition profiles, and optional Silero speech synthesis.
This is the next public release after 0.2.1 and includes the unpublished 0.3.0 changes.

### Changes since 0.2.1

- Optional GigaAM v3 CTC/RNNT dictation, with separate model/CPU engine downloads;
  independent office-server and cloud profiles.
- Microphone preparation before the recording signal and a new microphone icon.
- Optional Silero v5.5 with five Russian voices, previews, verified downloads,
  progress, cancellation and continuation.
- Local document library and WAV export; existing recordings and backups remain usable.
- SaluteSpeech cloud TTS, its credential and quota UI removed; STT settings and keys remain separate.

### Install and upgrade

Download **[Glagol_0.4.0_x64-setup.exe](https://github.com/dimasiksuleyman-sudo/glagol/releases/download/v0.4.0/Glagol_0.4.0_x64-setup.exe)** — 9,742,481 bytes (9.29 MiB).
This is the exact installer used in the Windows 10 manual test. It is unsigned;
SmartScreen may warn. Verify the source and SHA-256; if you trust the file,
choose “More info” → “Run anyway”.

Back up your 0.2.1 library in Settings and exit Glagol through its tray menu.
Run the 0.4.0 installer, choose **“Do not uninstall” («Не удалять»)** on the
existing-installation page and retain the original application directory.
The tested upgrade preserved five recordings, playback/export and STT settings/key.

Silero downloads separately: **145.4 MB model + 249.3 MB runtime**, with at least
**1.9 GB** free for installation. No system Python or CUDA is needed; synthesis
runs locally after installation. **Silero is optional and for noncommercial use
under CC BY-NC-SA 4.0**; Glagol itself is MIT. Dictation, including office-server
use, does not require Silero. Model/provider terms apply independently.
Yandex SpeechKit is not included.

### Verification and remaining coverage

Manual testing on September 13, 2026: Windows 10 Pro 22H2 x64, AMD FX-8300, 16 GB.
Confirmed clean installation, 0.2.1→0.4.0 upgrade, library restoration with a
safety backup, preservation of old recordings and STT settings, existing key
validation, Silero download/cancel/continuation, all five voice previews, short
text with numbers/Latin words, library playback and exported WAV playback.

**Manual QA is paused, not complete.** Long synthesis/cancellation, component
import/repair/removal, worker idle/exit behavior, live dictation after updating
and simultaneous STT/TTS are not yet manually verified on this PC. Crash,
timeout and parent-death scenarios were not separately fault-injected.
The unpublished 0.3.0 upgrade scenario was excluded. Previous-day automated
results are documented separately and do not replace this remaining manual QA.
