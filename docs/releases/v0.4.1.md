# Glagol 0.4.1 — быстрый запуск Silero / faster Silero startup

## Русский

Glagol 0.4.1 для Windows 10/11 x64 — патч-релиз локальной озвучки Silero.
Он убирает повторную долгую проверку компонентов при каждом запуске и делает
фоновую подготовку понятной в интерфейсе.

### Что изменилось

- После успешной полной проверки Glagol хранит техническую отметку 30 дней.
  При обычном запуске быстро сверяются возраст отметки и размер/время изменения
  модели, `python.exe` и `python311.dll`.
- Полная проверка повторяется раз в месяц, при изменении ключевых файлов или
  после ошибки worker. Первый запуск после обновления выполняет её один раз в фоне.
- Раздел «Озвучить» заранее загружает модель. Пока подготовка идёт, видны статус,
  движущийся progress bar, ориентир времени и подпись кнопки
  «Подготовка озвучки…».
- Готовый worker повторно используется и выгружается после 15 минут без озвучки,
  освобождая примерно 752 МБ на проверенном компьютере.
- В локальный технический лог добавлены безопасные длительности запуска,
  проверки, подготовки и синтеза. Текст, аудио, ключи и пути документов не пишутся.

### Установка и обновление

Скачайте **Glagol_0.4.1_x64-setup.exe** из assets этого выпуска —
9 777 903 байта (9,32 МиБ), SHA-256
`5e23d37d606b8fa529e96ab2dc139e4c195c9f6b81f74f0424ef5b174e45df21`. Перед
обновлением создайте резервную копию в настройках и завершите Glagol через
меню трея «Выход». При запросе существующей установки выберите «Не удалять»
и сохраните прежнюю папку. Библиотека, настройки и компоненты Silero остаются
на месте. Установщик не подписан: SmartScreen может показать предупреждение.

Silero устанавливается отдельно и предназначена для некоммерческого
использования по CC BY-NC-SA 4.0. Диктовка работает независимо от Silero.

### Проверка и ограничения

На Windows 11 25H2 x64, AMD Ryzen 7 7730U получены следующие результаты:

- миграционная полная проверка существующих компонентов — около 50 секунд один раз;
- следующие проверки отметки — 2–3 мс;
- готовность UI — 637–805 мс, загрузка и прогрев worker — 3,54–3,59 с;
- повторная подготовка готового worker — 0 мс;
- 806 символов: синтез 5232 мс, всего 5233 мс; 384 символа: 2574 мс;
- worker штатно выгружен через 901 926 мс простоя;
- пользователь вручную подтвердил новый статус и progress bar;
- тихое обновление установленной 0.4.0 до 0.4.1 завершилось с кодом 0;
  установленный EXE имеет FileVersion/ProductVersion 0.4.1, а его запуск дал
  проверку отметки 2 мс, UI 699 мс и прогрев 3873 мс;
- Rust: 330 PASS, 0 FAIL, 3 ignored hardware/native; отдельный регресс
  диктовки: 146 PASS, 0 FAIL, 1 ignored live-microphone.

Свежая живая диктовка через микрофон и новая чистая установка 0.4.1 вручную
не проверялись. Это не влияет на результаты автоматических
тестов и direct-run TTS QA, но не считается ручным PASS этих сценариев.

## English

Glagol 0.4.1 for Windows 10/11 x64 is a patch release for local Silero TTS.
It removes the repeated full component scan from normal launches and explains
background preparation in the UI.

### Changes

- A successful full verification creates a 30-day technical receipt. Normal
  launches quickly compare its age and the size/modification time of the model,
  `python.exe`, and `python311.dll`.
- Full verification runs monthly, after key files change, or after a worker
  failure. The first launch after upgrading performs it once in the background.
- Synthesize preloads the model and shows status, an animated progress bar,
  timing guidance, and “Preparing TTS…” while the action is unavailable.
- The ready worker is reused and unloads after 15 idle minutes, releasing roughly
  752 MB on the tested computer.
- Privacy-safe local timing events cover startup, verification, preparation and
  synthesis. They do not record text, audio, credentials or document paths.

### Install or upgrade

Download **Glagol_0.4.1_x64-setup.exe** from this release's assets —
9,777,903 bytes (9.32 MiB), SHA-256
`5e23d37d606b8fa529e96ab2dc139e4c195c9f6b81f74f0424ef5b174e45df21`. Create a
backup in Settings, exit Glagol through the tray menu, and run the installer.
Choose “Do not uninstall” for an existing installation and keep its directory.
The library, settings and Silero components remain in place. The installer is
unsigned, so SmartScreen may warn.

Silero is a separately installed noncommercial component under CC BY-NC-SA 4.0.
Dictation remains independent from Silero.

### Verification and limitations

Measured on Windows 11 25H2 x64 with AMD Ryzen 7 7730U:

- one migration full check of existing components: about 50 seconds;
- subsequent receipt checks: 2–3 ms;
- UI ready: 637–805 ms; worker load/warmup: 3.54–3.59 s;
- repeated preparation with the ready worker: 0 ms;
- 806 characters: 5232 ms synthesis, 5233 ms total; 384 characters: 2574 ms;
- worker unloaded normally after 901,926 ms idle;
- the user manually confirmed the new preparation status and progress bar;
- a silent update of the installed 0.4.0 to 0.4.1 exited successfully; the
  installed EXE reports FileVersion/ProductVersion 0.4.1 and its launch measured
  a 2 ms receipt check, 699 ms UI readiness and 3873 ms warmup;
- Rust: 330 PASS, 0 FAIL, 3 hardware/native ignored; focused dictation
  regression: 146 PASS, 0 FAIL, 1 live-microphone test ignored.

A fresh live-microphone dictation and a new clean 0.4.1 installation were not
manually exercised. This does not change the
automated or direct-run TTS results, but those scenarios are not claimed as a
manual PASS.
