# Glagol 0.6.3 — faster local dictation, optional speech, diagnostics

## English

Glagol 0.6.3 for Windows 10/11 x64. Version 0.6.2 was an unpublished test build; 0.6.3 is the next public release after 0.6.1.

- Faster Russian local dictation on older computers. Settings → Dictation → Recognition speed lets GigaAM compute on the graphics card (Vulkan) and choose the number of processor threads; one-click hints suggest the graphics card when Glagol has seen one and GigaAM CTC (now marked recommended) instead of RNNT. On a test PC without AVX2 (AMD FX-8300, Radeon RX 550), a 27-second phrase with GigaAM RNNT took about 5.5 s on the graphics card instead of about 28 s on the processor; with CTC the user reported it was faster still. The processor stays the default; if the graphics card cannot be used, Glagol falls back to the processor and shows a warning.
- The first Russian local dictation after start no longer re-hashes the model every time: a full SHA-256 check is reused for up to 30 days while the files are unchanged (about 3 s saved on that PC).
- Text to speech can be turned off in Settings → Local text to speech. Glagol then skips Silero verification at startup and preloading, hides the Synthesize page and opens Dictation first; models, acknowledgement and the library are kept.
- Settings → Diagnostics: a Detailed log switch and Open log folder. The log records the processor, recognition timings and how the dictation indicator was shown — never speech, recognized text, documents or keys.
- The hidden dictation indicator window is rebuilt after the display turns on, unlock, remote desktop changes, display changes and WebView2 process failures, not only after sleep; a delayed hide can no longer hide the indicator of a new dictation.
- Known issue: the dictation indicator may still disappear in some cases while dictation keeps working; the new log entries are meant to find the cause. Restarting Glagol from the tray brings it back.

Glagol 0.6.0 and later update from Settings → Updates → Check for updates → Install update. From 0.5.x, install manually: create a backup in Settings, quit Glagol from the tray, run the installer and keep the existing folder. The installer is unsigned for Windows, so SmartScreen may warn; update packages are signed with the Glagol update key.

Silero models remain separately licensed under CC BY-NC-SA 4.0 for noncommercial use. The application remains MIT; dictation does not require Silero.

## Русский

Глагол 0.6.3 для Windows 10/11 x64. Версия 0.6.2 была неопубликованной тестовой сборкой; 0.6.3 — следующий публичный выпуск после 0.6.1.

- Русская локальная диктовка быстрее на старых компьютерах. «Настройки» → «Диктовка» → «Скорость распознавания» позволяет считать GigaAM на видеокарте (Vulkan) и выбрать число потоков процессора; подсказки в один клик предлагают видеокарту, если Глагол её уже видел, и GigaAM CTC (теперь отмечена как рекомендуемая) вместо RNNT. На тестовом ПК без AVX2 (AMD FX-8300, Radeon RX 550) фраза на 27 секунд с GigaAM RNNT распознавалась на видеокарте примерно за 5,5 с вместо ~28 с на процессоре; с CTC, по словам пользователя, ещё быстрее. По умолчанию по-прежнему процессор; если видеокарту использовать не удалось, Глагол переходит на процессор и показывает предупреждение.
- Первая русская локальная диктовка после запуска больше не пересчитывает хеш модели каждый раз: полная проверка SHA-256 используется до 30 дней, пока файлы не меняются (на том ПК — около 3 с экономии).
- Озвучку можно выключить в «Настройки» → «Локальная озвучка». Тогда Глагол не проверяет Silero при запуске и не загружает её заранее, скрывает экран «Озвучить» и открывается на «Диктовке»; модели, согласие и библиотека сохраняются.
- «Настройки» → «Диагностика»: переключатель «Подробный журнал» и кнопка «Открыть папку журналов». В журнал пишутся процессор, время этапов распознавания и показ индикатора диктовки — без речи, распознанного текста, документов и ключей.
- Скрытое окно индикатора диктовки пересоздаётся после включения экрана, разблокировки, изменений удалённого рабочего стола, смены дисплея и сбоя процесса WebView2, а не только после сна; запоздавшее скрытие больше не прячет индикатор новой диктовки.
- Известная проблема: индикатор диктовки в отдельных случаях всё ещё может пропасть, хотя диктовка работает; новые записи журнала нужны, чтобы найти причину. Перезапуск Глагола через трей возвращает индикатор.

Глагол 0.6.0 и новее обновляется из «Настройки» → «Обновления» → «Проверить обновления» → «Установить обновление». С 0.5.x — вручную: создайте резервную копию в настройках, завершите Глагол через трей, запустите установщик и сохраните прежнюю папку. Установщик не подписан сертификатом Windows, возможно предупреждение SmartScreen; пакеты обновлений подписаны ключом обновлений Глагола.

Модели Silero по-прежнему имеют отдельную лицензию CC BY-NC-SA 4.0 для некоммерческого использования. Приложение остаётся MIT; диктовка не требует Silero.

## Validation and limits / Проверки и ограничения

TypeScript/production build, i18n check (279 keys), Rust fmt/clippy/test (356 passed, 6 ignored) passed in a Linux container; the Windows-only indicator and engine code passed `cargo clippy --target x86_64-pc-windows-msvc` in an isolated crate with the same pinned dependencies. The graphics-card path and timings were checked by the user on one PC (FX-8300, RX 550) with a test build; the indicator changes are not yet confirmed on Windows and stay under observation. A Vulkan driver hang or crash is not caught by the processor fallback, which is why the graphics card is opt-in. The update from an installed 0.6.x is verified after publication.

TypeScript/production build, проверка i18n (279 ключей), Rust fmt/clippy/test (356 passed, 6 ignored) прошли в Linux-контейнере; Windows-код индикатора и движка прошёл `cargo clippy --target x86_64-pc-windows-msvc` в отдельном крейте с теми же закреплёнными зависимостями. Путь через видеокарту и замеры пользователь проверил на одном ПК (FX-8300, RX 550) на тестовой сборке; изменения индикатора на Windows ещё не подтверждены и остаются под наблюдением. Зависание или падение драйвера Vulkan откат на процессор не ловит, поэтому видеокарта включается по выбору. Обновление из установленной 0.6.x проверяется после публикации.
