## English

Glagol 0.7.0 for Windows 10/11 x64, the next public release after 0.6.6.

**Text to speech**
- **Qwen3-TTS** — a second, optional offline engine with a lively voice and natural
  intonation for Russian and English. The models are Apache 2.0 and the runtime is
  MIT, so commercial use is allowed. About 1.3 GB is downloaded on demand and checked
  by SHA-256 before anything runs. Glagol picks the graphics card and, if it runs out
  of memory, moves to a safer mode or the processor and remembers it. On a laptop's
  integrated Radeon a minute of news takes about a minute and a half. Silero stays as
  the light engine.
- **Reading style** for Qwen3-TTS on the Synthesize page — even without emotion (the
  default), calm, news anchor, warm, cheerful or your own description — with «Listen».
- **Numbers, money, dates, times and abbreviations are read as words** in the right
  Russian case («980 млн акций», «в 7 регионах», «на уровне 16%», «300 кв. м»);
  English text follows English rules.
- **Pronunciation dictionary** («written as → read as», stress with «+»), CSV
  import/export, «Check a phrase» and «Listen».
- **Optional AI help for tricky numbers** through any OpenAI-compatible service
  (off by default; only short excerpts, at most a tenth of the text, are sent).
- **Do not read text in brackets** (Settings → Text to speech).
- New installations start with text to speech off.

**Dictation**
- **Server for other computers**: one computer with a graphics card serves Russian
  dictation to Glagol on other computers in the local network — the speech stays in
  the office; connection by pasting a code; access key always required.
- **Dictation by holding Ctrl+Win**, alongside the main shortcut (off by default).
- **Organization server**: load and filter the model list or enter a name; Glagol
  saves the profile after a short built-in audio test and warns when a provider
  removes the selected model.
- **Paste into the new Outlook** works: Glagol waits for the shortcut keys to be
  released and sends Ctrl+V once (GL-013).
- **Text goes only to the window where dictation started.** If another window, Windows
  search or Start is active by then, the text stays on the clipboard (GL-014).
- **Choosing local recognition takes effect at once** when the model is ready; unsaved
  fields survive switching settings tabs (GL-015).

**Help** covers every new feature with steps and a «Show» button.

Glagol 0.6.0 and later update from Settings → General → Updates. The installer is
not yet signed for Windows, so SmartScreen may warn: «More info → Run anyway».
Update packages are signed with the Glagol update key.

## Русский

Глагол 0.7.0 для Windows 10/11 x64 — следующий публичный выпуск после 0.6.6.

**Озвучка**
- **Qwen3-TTS** — второй необязательный офлайн-движок с живым голосом и естественной
  интонацией для русского и английского. Модели — Apache 2.0, программа — MIT:
  коммерческое использование разрешено. Около 1,3 ГБ скачивается по желанию и
  проверяется по SHA-256 до запуска. Глагол сам выбирает видеокарту, при нехватке
  памяти переходит в безопасный режим или на процессор и запоминает это. На
  встроенной видеокарте ноутбука минута новости озвучивается примерно за полторы
  минуты. Silero остаётся лёгким вариантом.
- **Манера чтения** Qwen3-TTS на экране «Озвучить» — ровно без эмоций (по
  умолчанию), спокойно, как диктор новостей, тепло, бодро или своё описание — с
  кнопкой «Послушать».
- **Числа, суммы, даты, время и сокращения читаются словами** в нужном падеже
  («980 млн акций», «в 7 регионах», «на уровне 16%», «300 кв. м»); английский текст —
  по английским правилам.
- **Словарь произношения** («как написано → как читать», ударение «+»), импорт и
  экспорт CSV, «Проверить фразу» и «Послушать».
- **Помощь ИИ со сложными числами** через любой OpenAI-совместимый сервис (по
  умолчанию выключена; уходят только короткие фрагменты — не больше десятой части).
- **Не читать текст в скобках** («Настройки» → «Озвучка»).
- Новая установка начинает с выключенной озвучкой.

**Диктовка**
- **Сервер для других компьютеров**: один компьютер с видеокартой раздаёт русскую
  диктовку Глаголу на других компьютерах локальной сети — речь не покидает офис;
  подключение вставкой кода; ключ доступа обязателен.
- **Диктовка по удержанию Ctrl+Win** вместе с основной клавишей (по умолчанию
  выключена).
- **Сервер организации**: список моделей с фильтром или имя вручную; Глагол
  сохраняет профиль после короткой проверки на встроенном аудио и предупреждает,
  если провайдер убрал выбранную модель.
- **Вставка в новый Outlook** работает: Глагол ждёт отпускания клавиш сочетания и
  отправляет Ctrl+V один раз (GL-013).
- **Текст вставляется только в то окно, где началась диктовка.** Если к этому времени
  активно другое окно, поиск Windows или «Пуск», текст остаётся в буфере (GL-014).
- **Выбор локального распознавания применяется сразу**, если модель готова;
  несохранённые поля не теряются при переходе между вкладками настроек (GL-015).

**Справка** описывает все новые функции с шагами и кнопкой «Показать».

Глагол 0.6.0 и новее обновляется из «Настройки» → «Общие» → «Обновления».
Установщик пока не подписан сертификатом Windows, возможно предупреждение
SmartScreen: «Подробнее → Выполнить в любом случае». Пакеты обновлений подписаны
ключом обновлений Глагола.
