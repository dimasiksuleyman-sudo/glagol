# Glagol 0.5.2 — interface touches

## English

Glagol 0.5.2 for Windows 10/11 x64 is a small interface release.

- Added: a GitHub link at the bottom of the sidebar opens the author's profile in the default browser.
- Fixed: in the Russian interface, the Settings item in the sidebar and the Settings page title are no longer shown in quotation marks.
- Known issue: on some occasions the dictation indicator can still disappear while dictation keeps inserting text; the cause is under investigation. Restarting Glagol from the tray brings the indicator back.

Upgrade over 0.5.x: create a backup in Settings, quit Glagol from the tray menu, run the installer and keep the existing folder. Documents, settings, keys and installed speech components stay in place. The installer is unsigned, so SmartScreen may warn.

Silero models remain separately licensed under CC BY-NC-SA 4.0 for noncommercial use. The application remains MIT; dictation does not require Silero.

## Русский

Глагол 0.5.2 для Windows 10/11 x64 — небольшой релиз интерфейса.

- Добавлено: ссылка GitHub внизу бокового меню открывает профиль автора в браузере по умолчанию.
- Исправлено: в русском интерфейсе пункт «Настройки» в боковом меню и заголовок страницы настроек больше не взяты в кавычки.
- Известная проблема: иногда индикатор диктовки всё ещё может пропасть, хотя текст продолжает вставляться; причина выясняется. Перезапуск Глагола через трей возвращает индикатор.

Обновление поверх 0.5.x: создайте резервную копию в настройках, завершите Глагол через меню трея «Выход», запустите установщик и сохраните прежнюю папку. Документы, настройки, ключи и установленные речевые компоненты остаются на месте. Установщик не подписан, возможно предупреждение SmartScreen.

Модели Silero по-прежнему имеют отдельную лицензию CC BY-NC-SA 4.0 для некоммерческого использования. Приложение остаётся MIT; диктовка не требует Silero.
