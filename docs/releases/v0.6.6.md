# Glagol 0.6.6 — hesitation sounds removed, dictation indicator restored on any background

## English

Glagol 0.6.6 for Windows 10/11 x64, the next public release after 0.6.5.

- Remove hesitation sounds. The sounds people make while thinking — "uh", "um", "er", "hmm" and the Russian «эм», «э-э», «м-м», «хм», «аа» — are removed from the dictated text, and spaces, commas and capitalization are repaired: «Эм-м, давай завтра.» becomes «Давай завтра.». If a dictation contained only such sounds, nothing is inserted. Words such as "like" or «ну», «вот», «типа» are kept: they are real words and cannot be told apart from their ordinary use without understanding the sentence. The switch is on the Dictation page and is on by default. Cleaning runs on the computer, without the network, for every recognition method.
- The dictation indicator check now works on any background. In 0.6.5 it trusted only light backgrounds, so an indicator lost over a dark window went unnoticed until Glagol rebuilt it after 10 idle minutes. Glagol now compares the screen with the colours the indicator can take, which works on light, dark and black backgrounds; only a background of almost the same colour as the indicator cannot be judged.
- A lost indicator is rebuilt and shown again during the same dictation, in about half a second, instead of after it (once per dictation).

On the test PC the indicator stayed visible through about three days of intensive dictation with the 0.6.6 test build (reported by the user).

Glagol 0.6.0 and later update from Settings → General → Updates → Check for updates → Install update (before 0.6.5: Settings → Updates). From 0.5.x, install manually: create a backup in Settings, quit Glagol from the tray, run the installer and keep the existing folder. The installer is unsigned for Windows, so SmartScreen may warn; update packages are signed with the Glagol update key.

## Русский

Глагол 0.6.6 для Windows 10/11 x64 — следующий публичный выпуск после 0.6.5.

- Звуки-заминки убираются. Звуки, которые произносят, когда думают, — «эм», «э-э», «м-м», «хм», «аа» и английские «uh», «um», «er», «hmm» — убираются из надиктованного текста, а пробелы, запятые и заглавная буква поправляются: «Эм-м, давай завтра.» превращается в «Давай завтра.». Если в диктовке были только такие звуки, ничего не вставляется. Слова вроде «ну», «вот», «типа» остаются: это настоящие слова, и без понимания смысла их не отличить от нужных. Переключатель «Убирать звуки-заминки» — на странице «Диктовка», по умолчанию включён. Чистка работает на компьютере, без сети, для любого способа распознавания.
- Проверка индикатора диктовки теперь работает на любом фоне. В 0.6.5 она доверяла только светлому фону, и индикатор, пропавший над тёмным окном, оставался незамеченным, пока Глагол не пересоздавал его после 10 минут простоя. Теперь Глагол сравнивает экран с цветами, которые может иметь индикатор, — это работает на светлом, тёмном и чёрном фоне; не определяется только фон почти того же цвета, что сам индикатор.
- Пропавший индикатор пересоздаётся и показывается снова в той же диктовке, примерно через полсекунды, а не после неё (один раз за диктовку).

На тестовом ПК индикатор не пропадал около трёх суток интенсивной диктовки на тестовой сборке 0.6.6 (со слов пользователя).

Глагол 0.6.0 и новее обновляется из «Настройки» → «Общие» → «Обновления» → «Проверить обновления» → «Установить обновление» (до 0.6.5: «Настройки» → «Обновления»). С 0.5.x — вручную: создайте резервную копию в настройках, завершите Глагол через трей, запустите установщик и сохраните прежнюю папку. Установщик не подписан сертификатом Windows, возможно предупреждение SmartScreen; пакеты обновлений подписаны ключом обновлений Глагола.

Модели Silero по-прежнему имеют отдельную лицензию CC BY-NC-SA 4.0 для некоммерческого использования. Приложение остаётся MIT; диктовка не требует Silero.

## Validation and limits / Проверки и ограничения

TypeScript check and production build, i18n check (353 keys), Rust fmt/clippy/test (373 passed, 6 ignored) passed in a Linux container; the Windows-only indicator code did not change in this release. On the PC the user checked a 0.6.6 test build: hesitation sounds were removed from real dictation, and the indicator stayed visible for about three days. The log of those days was not reviewed, so whether the new same-dictation repair actually fired is not confirmed. Why WebView2 stops presenting the indicator window is still unknown. The update from an installed 0.6.x is verified after publication.

Проверка TypeScript и production-сборка, проверка i18n (353 ключа), Rust fmt/clippy/test (373 passed, 6 ignored) прошли в Linux-контейнере; Windows-код индикатора в этом выпуске не менялся. На ПК пользователь проверил тестовую сборку 0.6.6: звуки-заминки убирались из настоящей диктовки, индикатор не пропадал около трёх суток. Журнал этих дней не разбирался, поэтому сработала ли новая починка в той же диктовке, не подтверждено. Почему WebView2 перестаёт выводить окно индикатора, по-прежнему неизвестно.
