# Glagol 0.6.0 — in-app updates

## English

Glagol 0.6.0 for Windows 10/11 x64 adds updates from inside the app.

- Settings → Updates shows the current version, checks GitHub for a newer release on request and, after confirmation, installs it: the update is downloaded, its digital signature is verified, Glagol closes, installs the new version and starts again. Documents, settings, keys and speech components are kept. Installation does not start during dictation or a speech operation; a file with an invalid signature is never installed.
- Check automatically at startup is off by default. While it is off, a reminder with Check now and Enable auto-check appears at startup at most once a month.
- The current version is shown in the sidebar.
- Known issue: on some occasions the dictation indicator can still disappear while dictation keeps inserting text; the cause is under investigation. Restarting Glagol from the tray brings the indicator back.

This is the last manual upgrade: install 0.6.0 over 0.5.x (create a backup in Settings, quit Glagol from the tray, run the installer and keep the existing folder). Later versions can be installed from Settings → Updates. The installer is unsigned for Windows, so SmartScreen may warn; update packages are signed with the Glagol update key.

Silero models remain separately licensed under CC BY-NC-SA 4.0 for noncommercial use. The application remains MIT; dictation does not require Silero.

## Русский

Глагол 0.6.0 для Windows 10/11 x64 добавляет обновление из программы.

- «Настройки» → «Обновления» показывает текущую версию, по запросу проверяет новую версию на GitHub и после подтверждения устанавливает её: обновление скачивается, его цифровая подпись проверяется, Глагол закрывается, ставит новую версию и запускается снова. Документы, настройки, ключи и речевые компоненты сохраняются. Во время диктовки или операции озвучки установка не начинается; файл с неверной подписью не устанавливается.
- «Проверять автоматически при запуске» по умолчанию выключено. Пока выключено, при запуске не чаще раза в месяц появляется напоминание с кнопками «Проверить сейчас» и «Включить автопроверку».
- Текущая версия показана в боковом меню.
- Известная проблема: иногда индикатор диктовки всё ещё может пропасть, хотя текст продолжает вставляться; причина выясняется. Перезапуск Глагола через трей возвращает индикатор.

Это последнее ручное обновление: установите 0.6.0 поверх 0.5.x (создайте резервную копию в настройках, завершите Глагол через трей, запустите установщик и сохраните прежнюю папку). Следующие версии можно ставить из «Настройки» → «Обновления». Установщик не подписан сертификатом Windows, возможно предупреждение SmartScreen; пакеты обновлений подписаны ключом обновлений Глагола.

Модели Silero по-прежнему имеют отдельную лицензию CC BY-NC-SA 4.0 для некоммерческого использования. Приложение остаётся MIT; диктовка не требует Silero.
