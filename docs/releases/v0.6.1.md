# Glagol 0.6.1 — what's new before updating

## English

Glagol 0.6.1 for Windows 10/11 x64 is the first release delivered through in-app updates.

- Added: the update confirmation shows what is new in the offered version. It is visible from the next update after 0.6.1, because the confirmation is drawn by the installed version.
- Known issue: on some occasions the dictation indicator can still disappear while dictation keeps inserting text; the cause is under investigation. Restarting Glagol from the tray brings the indicator back.

Glagol 0.6.0 updates itself: Settings → Updates → Check for updates → Install update (or the notification when the automatic check is on). From 0.5.x, install manually: create a backup in Settings, quit Glagol from the tray, run the installer and keep the existing folder. The installer is unsigned for Windows, so SmartScreen may warn; update packages are signed with the Glagol update key.

Silero models remain separately licensed under CC BY-NC-SA 4.0 for noncommercial use. The application remains MIT; dictation does not require Silero.

## Русский

Глагол 0.6.1 для Windows 10/11 x64 — первый выпуск, который доставляется обновлением из программы.

- Добавлено: окно подтверждения обновления показывает, что нового в предлагаемой версии. Это видно со следующего обновления после 0.6.1, потому что окно рисует уже установленная версия.
- Известная проблема: иногда индикатор диктовки всё ещё может пропасть, хотя текст продолжает вставляться; причина выясняется. Перезапуск Глагола через трей возвращает индикатор.

Глагол 0.6.0 обновляется сам: «Настройки» → «Обновления» → «Проверить обновления» → «Установить обновление» (или уведомление при включённой автопроверке). С 0.5.x — вручную: создайте резервную копию в настройках, завершите Глагол через трей, запустите установщик и сохраните прежнюю папку. Установщик не подписан сертификатом Windows, возможно предупреждение SmartScreen; пакеты обновлений подписаны ключом обновлений Глагола.

Модели Silero по-прежнему имеют отдельную лицензию CC BY-NC-SA 4.0 для некоммерческого использования. Приложение остаётся MIT; диктовка не требует Silero.
