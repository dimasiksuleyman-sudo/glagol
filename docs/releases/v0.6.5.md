# Glagol 0.6.5 — clearer interface with help, hardware recommendation, reliable dictation indicator

## English

Glagol 0.6.5 for Windows 10/11 x64. Version 0.6.4 was an unpublished test build; 0.6.5 is the next public release after 0.6.3.

- A clearer interface. Settings are split into Dictation, Text to speech and General tabs, and rarely used parts (model management, advanced options, Silero components and license) are collapsed. The Dictation page starts with a one-line readiness status and keeps only the daily controls. The Library is a compact list with one shared player and a search for long lists. The speech language on Synthesize sits next to the voice.
- Built-in Help: short steps for common tasks; Show opens the right screen and highlights the real button or switch. A «Did you know?» card occasionally suggests a feature you have not used yet (weekly in the first month, then monthly) and can be turned off.
- Hardware recommendation for Russian local dictation. At startup Glagol detects whether the processor has AVX2 and whether there is a discrete graphics card (without loading the model, once the Russian dictation engine is downloaded) and recommends GigaAM CTC on the graphics card, or CTC on the processor; without AVX2 and without a graphics card it says that local recognition will be slow and suggests an organization server or the cloud. Settings → Dictation → Recognition speed → Apply recommendation downloads CTC if needed and selects the device. Nothing changes until you click.
- Recognition speed shows the waiting time per 10 seconds of speech for recent dictations.
- The dictation indicator no longer disappears after a long idle period: it is rebuilt after 10 minutes without use, and after each show Glagol checks a few screen pixels within the indicator; if it did not reach the screen, Glagol logs it and rebuilds it after that dictation. Only brightness numbers are logged; the pixels are not stored.
- The indicator has a light and a dark outline, so it is visible on light and dark backgrounds.

On the test PC (AMD FX-8300 without AVX2, Radeon RX 550), GigaAM CTC on the graphics card recognized about 9 seconds of speech in about 0.7 s.

Glagol 0.6.0 and later update from Settings → Updates → Check for updates → Install update (from 0.6.5: Settings → General → Updates). From 0.5.x, install manually: create a backup in Settings, quit Glagol from the tray, run the installer and keep the existing folder. The installer is unsigned for Windows, so SmartScreen may warn; update packages are signed with the Glagol update key.

Silero models remain separately licensed under CC BY-NC-SA 4.0 for noncommercial use. The application remains MIT; dictation does not require Silero.

## Русский

Глагол 0.6.5 для Windows 10/11 x64. Версия 0.6.4 была неопубликованной тестовой сборкой; 0.6.5 — следующий публичный выпуск после 0.6.3.

- Понятнее интерфейс. Настройки разделены на вкладки «Диктовка», «Озвучка» и «Общие», редкое свёрнуто (управление моделями, дополнительные параметры, компоненты и лицензия Silero). Страница «Диктовка» начинается со строки готовности и содержит только ежедневное. «Библиотека» — компактный список с одним общим плеером и поиском для длинных списков. Язык речи на «Озвучить» стоит рядом с голосом.
- Встроенная «Справка»: короткие шаги для частых задач; «Показать» открывает нужный экран и подсвечивает настоящую кнопку или переключатель. Карточка «Знаете ли вы?» иногда подсказывает функцию, которой вы ещё не пользовались (раз в неделю в первый месяц, потом раз в месяц), и её можно отключить.
- Рекомендация по железу для русской локальной диктовки. При запуске Глагол определяет, есть ли у процессора AVX2 и есть ли дискретная видеокарта (не загружая модель, если движок русской диктовки уже скачан), и рекомендует GigaAM CTC на видеокарте или CTC на процессоре; без AVX2 и без видеокарты честно предупреждает, что локально будет медленно, и советует сервер организации или облако. «Настройки» → «Диктовка» → «Скорость распознавания» → «Применить рекомендацию» при необходимости скачивает CTC и включает нужное устройство. Без нажатия ничего не меняется.
- «Скорость распознавания» показывает время ожидания на 10 секунд речи у последних диктовок.
- Индикатор диктовки больше не пропадает после долгого простоя: он пересоздаётся после 10 минут без использования, а после каждого показа Глагол проверяет несколько пикселей экрана в пределах индикатора; если он не попал на экран, Глагол пишет это в журнал и пересоздаёт его после этой диктовки. В журнал попадают только числа яркости, сами пиксели не сохраняются.
- Индикатор обведён светлым и тёмным контуром и виден на светлом и тёмном фоне.

На тестовом ПК (AMD FX-8300 без AVX2, Radeon RX 550) GigaAM CTC на видеокарте распознавала около 9 секунд речи примерно за 0,7 с.

Глагол 0.6.0 и новее обновляется из «Настройки» → «Обновления» → «Проверить обновления» → «Установить обновление» (с 0.6.5: «Настройки» → «Общие» → «Обновления»). С 0.5.x — вручную: создайте резервную копию в настройках, завершите Глагол через трей, запустите установщик и сохраните прежнюю папку. Установщик не подписан сертификатом Windows, возможно предупреждение SmartScreen; пакеты обновлений подписаны ключом обновлений Глагола.

Модели Silero по-прежнему имеют отдельную лицензию CC BY-NC-SA 4.0 для некоммерческого использования. Приложение остаётся MIT; диктовка не требует Silero.

## Validation and limits / Проверки и ограничения

TypeScript/production build, i18n check (351 keys), Rust fmt/clippy/test (360 passed, 6 ignored) passed in a Linux container; the Windows-only indicator code passed `cargo clippy --target x86_64-pc-windows-msvc` in an isolated crate with the same pinned dependencies. The user installed a 0.6.4 test build with the indicator changes on the PC and reported the indicator visible; the hardware recommendation, the new layout and Help were checked in a browser with mocked data, in English and Russian, and on Windows only through the signed release build. The graphics card is still enabled only by the user's click: a Vulkan driver hang or crash is not caught by the processor fallback. The update from an installed 0.6.x is verified after publication.

TypeScript/production build, проверка i18n (351 ключ), Rust fmt/clippy/test (360 passed, 6 ignored) прошли в Linux-контейнере; Windows-код индикатора прошёл `cargo clippy --target x86_64-pc-windows-msvc` в отдельном крейте с теми же закреплёнными зависимостями. Пользователь установил тестовую 0.6.4 с изменениями индикатора на ПК и сообщил, что индикатор виден; рекомендация по железу, новая раскладка и «Справка» проверены в браузере на тестовых данных на обоих языках, а на Windows — только через подписанную сборку выпуска. Видеокарта по-прежнему включается только нажатием пользователя: зависание или падение драйвера Vulkan откат на процессор не ловит. Обновление из установленной 0.6.x проверяется после публикации.
