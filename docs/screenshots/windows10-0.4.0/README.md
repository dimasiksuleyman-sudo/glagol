# Скриншоты Windows 10 — Glagol 0.4.0

Оригинальные PNG, присланные пользователем 2026-09-13 во время ручного прогона.
Пользователь попросил сохранять их для будущей документации GitHub. Файлы
извлечены из локальной записи именно этого чата без изменения изображения;
каждая копия побайтово сверена с вложением. Размеры, время получения и SHA-256:
[manifest.json](manifest.json). Исходное имя вложения не предоставлялось;
имена файлов назначены по подтверждённым шагам QA.
