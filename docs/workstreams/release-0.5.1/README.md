# Выпуск Glagol 0.5.1

Цель: патч-релиз с исправлением таблетки диктовки после сна (серия overlay-resume).
Основание: сообщение пользователя 2026-10-07 «Слей в мейн. Опубликуй релиз с
исправлениями» — явное разрешение на merge в main, тег и GitHub Release.
В scope: версия 0.5.1 во всех источниках, CHANGELOG, release notes, README и
обе USER_GUIDE, NSIS на Windows пользователя, PR/merge, тег v0.5.1, Release.
Вне scope: новые изменения приложения, обновление зависимостей.

Решения:
- Облачная сессия не имеет инструмента загрузки assets: NSIS собирает и
  прикрепляет к Release пользователь на Windows; сессия готовит тексты и
  проверяет опубликованный Release через GitHub API.
- Merge PR методом merge commit, чтобы SHA из журналов overlay-resume остались
  достижимыми из main.

Критерии: гейты версии/контекста/Rust/TS, NSIS с размером и SHA-256, ручная
проверка обновления, опубликованный Release с совпадающим хешем asset.
