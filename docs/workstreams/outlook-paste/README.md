# Вставка диктовки и выбор режима в Windows

Цель — предсказуемая автовставка и сохранение режима диктовки.
Основание — [GL-013, GL-014 и GL-015](../../findings/README.md).

- **O1.** Разобрать путь основного хоткея и Ctrl+Win. На Windows ограниченно ждать
  отпускания Ctrl, Shift, Alt и Win, затем отправлять Ctrl+V одним вызовом.
  Проверять фокус и сохранять возможность вставить текст вручную при отказе.
  В подробном журнале указывать категории модификаторов и время. Без Escape.
  Запасной ввод через Unicode рассматривать, если Ctrl+V окажется ненадёжным.
- **O2.** Пользователь проверяет вставку в новом Outlook на Windows.
  [Подтверждение](log.md#o2-подтверждение-пользователя).
- **O3.** Фиксировать исходное окно при нажатии хоткея, исключить оболочку
  Windows и отправлять маску «Пуска» раньше, пока Ctrl+Win удерживается.
- **O4.** Сразу активировать выбранную локальную модель, если все файлы готовы.
  Видимое действие у выбора режима и сохранение черновиков между вкладками
  для изменений, требующих подтверждения.
- **O5.** Пользователь проверяет оба исправления на Windows 11.
  [Шаги](log.md#o5-ручная-проверка-на-windows-11).

Статусы — в [state.json](state.json), наблюдения — в [log.md](log.md).
