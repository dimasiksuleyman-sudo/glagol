# Быстрый запуск локальной озвучки

Цель: сократить видимое ожидание перед первой озвучкой Silero после запуска
Glagol, не ослабляя полную проверку закреплённых файлов перед исполнением.

Основание: пользователь 2026-09-14 согласовал безопасный вариант — полная
проверка в фоне после запуска, предварительная подготовка при входе на экран
озвучки и более длительное удержание worker.

В scope: кеш результата полной проверки только в памяти текущего процесса,
фоновая проверка уже установленного и принятого Silero, явная команда подготовки
для frontend, прогрев на экране синтеза, увеличение idle timeout, тесты и
пользовательская документация. Вне scope: месячный доверенный кеш на диске,
ослабление SHA-256, изменение модели/runtime и публикация релиза.

Решение: никакой файл runtime не исполняется до успешной полной проверки в
текущем процессе. Фоновая и пользовательская подготовка должны разделять один
результат и не запускать параллельные проверки или worker.

Критерии: Rust-тесты подтверждают однократную проверку и жизненный цикл;
TypeScript/build и штатные Rust-гейты проходят; документация описывает фоновую
подготовку, расход памяти и отсутствие повторной загрузки/распаковки.

Статусы находятся только в state.json, результаты — в append-only log.md.
