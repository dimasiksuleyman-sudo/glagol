# Выбор и проверка моделей диктовки

Цель — выбрать рабочую модель сервера организации и заметить, если провайдер
позже её снимет. Основание — согласованная задача и [очередь](../../roadmap.md).

- **M1.** Загрузить `GET /models` с ограничением размера ответа, выбрать
  модель с фильтром или ввести имя вручную. Проверить выбранную модель на
  коротком встроенном WAV без речи пользователя и сохранить только после
  успешного ответа. Сохранить существующие правила TLS, частной сети и keyring.
  Описать работу в справке, руководствах, README и CHANGELOG.
- **M2.** По отдельной просьбе добавить ручную проверку и тихую проверку при
  запуске не чаще раза в неделю для активного облачного или серверного профиля.
  Показывать результат и дату в настройках диктовки. Проверять только сохранённый
  адрес через `GET /models` и хранить ключ в keyring. Отсутствие каталога не
  подтверждает снятие модели. Предупреждение о снятии не блокирует диктовку.
  Поднять предел ответа до 4 МиБ и проверить границу.

Локальные модели вне объёма. Критерии M1 — проверки Rust и фронтенда,
в том числе сценарии сервера Глагола, ручного ввода и ошибки проверки.
Статусы — в [state.json](state.json), результаты — в [log.md](log.md).
