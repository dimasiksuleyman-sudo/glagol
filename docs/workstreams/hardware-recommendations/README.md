# Рекомендации модели и настроек по железу

Цель: Глагол сам рекомендует модель и настройки локальной диктовки под
компьютер пользователя, а не ждёт, пока человек найдёт их в настройках.
Основание: вопрос пользователя 2026-11-09 — «а программа сама может
рекомендовать в зависимости от железа рекомендованную модель и настройки?
Допустим, на ноутбуке тоже CTC надо ставить?» и просьба записать это в TODO
для следующих агентов.

Что уже есть (0.6.3, серия dictation-speed): CTC первая в каталоге и
отмечена «рекомендуется»; подсказки «Считать на видеокарте» и «Перейти на CTC»
в «Скорости распознавания». Ограничение: видеокарта известна только после
первой загрузки runtime GigaAM в процессе (engine::discrete_gpu).

План (уточнить с пользователем перед началом):
1. Знание о железе заранее: признаки CPU (AVX2) уже есть в diagnostics.rs;
   устройства Vulkan — опросить runtime transcribe.cpp без загрузки модели
   (transcribe_init_backends_default + transcribe_device_*), если runtime
   установлен, вне главного потока.
2. Первая настройка (DictationSetupCard) и выбор русской локальной модели:
   предложить «CTC + видеокарта» при дискретной Vulkan-видеокарте, иначе
   «CTC + процессор»; без AVX2 и без видеокарты — честно предупредить о
   скорости и предложить офисный/облачный режим.
3. Подсказка по фактам: хранить rtf последних N локальных диктовок (только
   числа); если медленно (например, rtf > 0,5 на фразах > 3 с) — показать
   конкретный совет (видеокарта/CTC/потоки) на странице «Диктовка».
4. Ничего не включать молча: видеокарта по-прежнему по кнопке (зависание
   драйвера откат на CPU не ловит).

Данные: ПК пользователя (FX-8300 без AVX2, RX 550) — RNNT CPU rtf ≈1,1,
RNNT Vulkan rtf ≈0,2; CTC на видеокарте пользователь оценил как ещё быстрее и
«быстрее, чем на ноутбуке» (reported, без журнала). Журнала ноутбука (AVX2) нет:
для него рекомендации нужно сначала измерить.

Вне scope: смена моделей/движка, автоматическое включение GPU, телеметрия.
