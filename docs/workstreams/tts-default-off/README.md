# Озвучка выключена по умолчанию при новой установке

Цель: новый пользователь начинает с диктовки; озвучка документов (Silero)
выключена и не предлагает скачивать модели, пока её не включат в настройках.
Основание: сообщение пользователя 2026-11-19 — «озвучка по умолчанию
отключена, модели не скачиваются для первого инсталла»; решения в тот же день:
только для новых установок, на первом запуске — строка-подсказка, задача первая
в [очереди](../../roadmap.md).

Сейчас (0.6.6):
- `src-tauri/src/preferences.rs`: `get()` читает `tts_enabled` с умолчанием
  `"1"`; `initialize(conn, existing)` один раз (`preferences_v1`) пишет
  стартовые ключи и различает новую установку (`existing = false`) и обновление.
- `src/components/Onboarding.tsx`: шаг «speech» показывает
  `<DictationSetupCard />` и `<TtsSection compact />` рядом.
- Модели и так скачиваются только по нажатию (Silero — после согласия с
  лицензией), но карточка на первом запуске подталкивает к установке.
- Выключатель озвучки есть с 0.6.3: `set_tts_enabled`/`activate_tts`;
  `src/App.tsx` не монтирует «Озвучить», `AppShell` убирает пункт меню,
  Silero не проверяется и не прогревается.

Направление:
1. `initialize()` при `existing = false` пишет `tts_enabled = "0"`.
   Обновления не трогаются: у них ключа нет (прежнее умолчание `"1"`) или
   уже сохранён выбор пользователя. Миграция схемы не нужна (ключ в
   `app_settings`).
2. Первый запуск: вместо `<TtsSection compact />` — строка «Озвучку документов
   можно включить позже: Настройки → Озвучка» (EN/RU, `src/i18n`); карточка
   диктовки остаётся; если озвучка уже включена (обновление), карточка
   показывается как сейчас.
3. Включение в «Настройки» → «Озвучка» (`TtsSection`) ведёт в существующий
   поток установки и согласия Silero, без автоскачивания.
4. Тесты в `preferences.rs`: свежая БД → выключено; БД обновления → включено;
   выбор сохраняется. «Справка»/tours и карточка «Знаете ли вы?»
   (`src/lib/tours.ts`, `src/lib/tips.ts`) — проверить ссылки на озвучку при
   выключенной озвучке.
5. Документы: USER_GUIDE RU/EN (первый запуск, раздел Silero), README обе
   части, CHANGELOG.

Проверка: cargo fmt/clippy/test, `pnpm exec tsc --noEmit`, `pnpm build`;
вручную — чистая установка в отдельном профиле Windows или ВМ (не на рабочей
библиотеке) и обновление поверх 0.6.x с включённой озвучкой.
Вне scope: удаление уже установленных моделей, изменение для обновлений,
смена моделей Silero.
