# Qwen3-TTS: качественные голоса с коммерческой лицензией

> План, согласованный 2026-11-20. Журнал — [log.md](log.md) (прослушивание,
> эксперименты с нормализацией); связанная серия —
> [tts-normalization](../tts-normalization/README.md).

## Context

Пользователь сравнил демо: «Квен обладает более живой озвучкой, меньше
синтетического привкуса»; «квен — это маст-хэв»; «слабый компьютер — не повод
думать, что у других такой же». Silero лицензирован CC BY-NC-SA (только
некоммерческое) — «силера не подходит для организации, поэтому логично заменить
его квен»; у организации будет сервер, который потянет Qwen. Qwen3-TTS (Alibaba,
январь 2026): 0.6B и 1.7B, **Apache 2.0**, 10 языков, включая русский и
английский. Сценарий пользователя: «Квен 1.7 с нормализацией цифр и сокращений
— топчик для прослушивания новостей, с выбором языка».

Запуск без Python возможен: есть C++/GGML-порты (`qwen3-tts.cpp` и форки:
predict-woo, Danmoreng — CPU/CUDA, Csavoldi — Vulkan) и GGUF-веса (Q4–Q8) —
та же основа, что у нашего GigaAM (transcribe.cpp/ggml с Vulkan). Сведения из
README проектов, не проверены: лицензии, поддержка, скорость.

## Шаги

### Q1. Прослушивание — выполнено (2026-11-20).

### Q2. Выбор движка и замер (спайк)
- Сравнить порты: лицензия (нужна MIT/Apache), активность, Windows-сборка,
  Vulkan (AMD+NVIDIA) и CUDA, поддержка CustomVoice/русского, стриминг,
  размер; выбрать один и закрепить версию (commit SHA).
- Сборка своими силами (CI-задача только по тегам, артефакт хранится в
  GitHub Releases Глагола с SHA-256 — как прочие компоненты); GGUF 0.6B/1.7B
  в Q8/Q4 — закреплённые файлы с SHA-256.
- Замер: ПК сына (GTX 1060 6 ГБ: Vulkan и CUDA), ПК пользователя (RX 550,
  Vulkan), процессор (ноутбук Lunnen 16, AVX2): скорость (отношение времени синтеза к
  длительности), видеопамять, качество Q4 vs Q8 на русской новости.
- Запасной путь, если порты не годятся: Python-воркер как у Silero (закреплённые
  PyTorch-колёса), только для NVIDIA.

### Q3. Движок в Глаголе
- `tts/qwen/`: загрузка закреплённых файлов (рантайм + GGUF), проверка
  SHA-256 и квитанция 30 дней (как у Silero/GigaAM), согласие не требуется
  (Apache 2.0), но лицензия показывается.
- Реализация `TtsBackend` (`src-tauri/src/tts/mod.rs`): чанки → WAV 24 кГц в
  существующий конвейер (временный WAV → одна строка в БД); отмена, таймаут,
  одна операция за раз (общий замок озвучки).
- Устройство: процессор / видеокарта (Vulkan; CUDA — если выбранный порт
  быстрее), откат на процессор при ошибке — по образцу GigaAM.
- Голоса: встроенные голоса CustomVoice, выбор RU/EN; клонирование голоса —
  вне первой версии.
- Нормализация: только через серию tts-normalization (N1 — обязательная
  зависимость), ударения «+» убираются.

#### Q3: архитектура по итогам Q2 (черновик 2026-11-20)

- **Рантайм:** qwentts.cpp (MIT), собранный нашей CI-задачей с
  `-DQWEN_SHARED=ON`: `qwen.dll` (только символы `qt_*`) + `ggml*.dll`
  (CPU-варианты, Vulkan; CUDA — отдельным пакетом при пользе). Архив
  публикуется в выпусках Глагола с SHA-256 и скачивается по требованию, как
  Moonshine; в установщик не входит.
- **Процесс:** скрытый дочерний режим того же EXE (как Moonshine), загружает
  `qwen.dll` после проверки файлов, ограниченный stdio-протокол (текст, голос,
  язык → PCM 24 кГц кусками). **Не `tts-server.exe`:** у него нет ключа, а
  локальный HTTP-порт без авторизации противоречит инварианту «HTTP-порт не
  открывается» для движков озвучки. Падение драйвера видеокарты не роняет
  Глагол; отмена/таймаут/выход родителя завершают процесс.
- **Устройство:** авто (видеокарта → процессор) с ручным выбором.
  `clamp_fp16` включать, когда Vulkan сообщает `fp16: 0` (RX 550 без него
  давал пустой звук); длину куска декодера (`codec_chunk_dur`, по умолчанию
  24 с) подбирать по видеопамяти — на 2 ГБ декодер просил 885 МБ одним
  куском и падал; при нехватке памяти — повтор на процессоре.
- **Узкое место на процессоре** — декодер звука (на Sandy Bridge 62 с из 85),
  поэтому для слабых машин основной путь — Q5 (сервер), а не локальный Qwen.
- **Голоса:** 9 именных голосов CustomVoice; русский у ryan — «без акцента,
  живой» (пользователь, 2026-11-20); остальные проверить на слух.
  Клонирование своего голоса (модель Base) — после первой версии.
- **Лицензии:** модели Apache 2.0, рантайм MIT — согласия «только
  некоммерческое», как у Silero, не требуется; тексты лицензий показываются.

### Q4. Интерфейс
- «Настройки» → «Озвучка»: выбор движка «Qwen3 — качественный (Apache 2.0,
  лучше с видеокартой)» / «Silero — лёгкий (только некоммерческое
  использование)»; размер модели 0.6B/1.7B; рекомендация по железу
  (видеопамять из пробы оборудования, как у распознавания).
- Новая установка: Qwen по умолчанию, если есть видеокарта ≥ 4 ГБ, иначе
  предложение 0.6B на процессоре или Silero; озвучка по-прежнему выключена до
  включения пользователем.

### Q5. Озвучка через сервер Глагола (для организаций)
- На сервере Глагола (серия lan-server) — `POST /v1/audio/speech`
  (OpenAI-совместимый) поверх Qwen; клиент «Сервер организации» получает
  режим озвучки через сервер; тот же ключ доступа и частные сети.

### Q6. Судьба Silero и документы
- Решение пользователя после Q2–Q4: оставить Silero как «лёгкие голоса» для
  слабых домашних ПК или убрать; README/USER_GUIDE RU/EN — позиционирование
  «диктовка, озвучка и сервер без облака, коммерчески чисто с Qwen».

## Риски
Скорость на слабых видеокартах; качество GGUF-квантования для русского;
зрелость C++-портов (возможен свой форк); объём загрузки (1–4 ГБ).
