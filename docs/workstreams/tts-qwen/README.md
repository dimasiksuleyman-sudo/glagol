# Qwen3-TTS: более человечные голоса с коммерческой лицензией

Основание: пользователь 2026-11-20 спросил о новых моделях озвучки «с отзывами
более человеческие»; после обзора — «давай обязательно пощупаем КВЕН».

Что известно (по карточкам моделей и техническому отчёту Qwen, не проверено
на нашем железе):
- Qwen3-TTS (Alibaba, январь 2026), модели 0.6B и 1.7B (Base, CustomVoice,
  VoiceDesign), лицензия **Apache 2.0** — коммерческое использование
  разрешено (у Silero — CC BY-NC-SA, только некоммерческое);
- 10 языков, включая русский и английский; клонирование голоса по ~3 с;
- по обзорам нужна видеокарта (упоминают от 6 ГБ видеопамяти) — на
  процессоре ожидается медленно; эталонная реализация — Python/PyTorch.

Источники: github.com/QwenLM/Qwen3-TTS, huggingface.co/Qwen
(Qwen3-TTS-12Hz-1.7B-CustomVoice, -1.7B-Base), arXiv 2601.15621.

Вопросы к оценке: качество русского (ударения, интонация, числа) против
Silero; скорость на GTX 1060 6 ГБ и RX 550; размер загрузки; можно ли
выполнять без Python (ONNX/ggml) в духе текущих компонентов; как
совмещать с Silero (Silero — слабые ПК, Qwen — ПК с видеокартой).
Альтернатива для сравнения: CosyVoice 3 (Apache 2.0, русский есть).
Вне scope до решения Q3: любая интеграция в приложение.
