# Журнал: Qwen3-TTS

## 2026-11-20T10:30:00.000Z — серия создана

Обзор открытых TTS 2026: Qwen3-TTS (Apache 2.0, RU/EN) — главный кандидат,

Chatterbox — русский в новой версии не подтверждён. Q1 — прослушивание демо.

## 2026-11-20T12:00:00.000Z — Q1: прослушивание (reported)

Пользователь сравнил демо Qwen3-TTS с Silero на новостном тексте: «Квен обладает
более живой озвучкой, меньше синтетического привкуса». Для обеих моделей текст
нужно нормализовать: «980 млн» прозвучало как «девяносто восемдесят малерад».
Предложения пользователя: словарь, который можно дополнять самому; по разрешению
в настройках — отправлять часть текста в ИИ-модель для нормализации; «Квен 1.7 с
нормализацией цифр и сокращений был бы топчик для прослушивания новостей, с
выбором языка».

## 2026-11-20T13:00:00.000Z — эксперимент: ИИ-нормализация фрагментами (метод пользователя)

Ключ AITunnel сохранён пользователем в секретах облачной среды (форма
request_credential; в чат и репозиторий не попадал). Скрипт в песочнице сессии:
из текста вырезаются только фрагменты с числами/валютами/сокращениями/латиницей
(± 1 слово до и 2 после, в пределах предложения), одним запросом уходят модели
(temperature 0, ответ — JSON-массив той же длины), ответы вставляются на место.
На новостном тексте из 2 абзацев ушло 8 фрагментов (~250 токенов на вход).
Результаты:
- gemini-3.5-flash-lite — 1,9 с, 244/151 токенов; почти всё верно
  («восьмисот двадцати пяти миллионов», «полтора триллиона», «Антропик»,
  «ай-пи-о»); ошибка: «восемьдесят один целую три десятых».
- gemini-3.5-flash — 9,2 с (2154 токена «размышления»); всё верно, включая
  «восемьдесят одну целую три десятых миллиарда долларов».
- gpt-4.1-nano — 1,6 с; ошибки падежа («восемьсот двадцати пяти», «один целых»),
  SpaceX не переведён.
- deepseek-v4-flash — 19,6 с; падеж «запланированных восемьсот двадцать пять» —
  ошибка; «восемьдесят один миллиард триста миллионов» — допустимо.
- qwen3.8-27b — 40,5 с (6194 токена размышления); как DeepSeek.
- qwen3.8-flash — не ответил за 120 с.
- gigachat-2 — 1,9 с; не перевёл «980», «825», Claude, IPO.
Вывод: метод фрагментов работает; лучший баланс — gemini-3.5-flash-lite
(по умолчанию) или gemini-3.5-flash (точнее, медленнее). Отправляется ~5–10 %
текста новости.

## 2026-11-20T13:40:00.000Z — сравнение цены: AITunnel и RouterAI

Пользователь сохранил ключ RouterAI (форма request_credential; адрес
`https://routerai.ru/api/v1`, OpenAI-совместимый, 617 моделей). Тот же текст,
те же 8 фрагментов. Цены по скриншоту AITunnel и `usage.cost` RouterAI (руб.):
- gemini-3.5-flash-lite: AITunnel 0,10 — RouterAI 0,049 (2,4 с, 244/153 токенов);
  ошибка «восемьдесят один целую» повторилась; в ответе появилось ударение
  «выручи́в» (комбинирующий акцент) — при встраивании удалять такие знаки.
- gemini-3.5-flash (по умолчанию): AITunnel 3,96 — RouterAI 2,57 (10,5 с,
  2645 токенов рассуждения); «Клода» — ошибка падежа.
- gemini-3.5-flash, reasoning effort low: RouterAI 1,46 (9,8 с), всё верно.
- reasoning {enabled:false}: не отключилось (2154 токена, 2,10 руб.).
Вывод: flash-lite в 30–50 раз дешевле flash при одной типичной ошибке;
RouterAI примерно вдвое дешевле AITunnel на этих моделях. Провайдер и модель
должны выбираться пользователем (OpenAI-совместимый адрес + ключ).

Выбор: **qwentts.cpp**, закреплён коммит 2edb35f87b709a070b2d5379f77e5c52a1daa585
(подмодуль ggml-форка ef4555b7). Веса: HF Serveurperso/Qwen3-TTS-GGUF (Apache

сервер Глагола), C ABI — для Q3.

Важно для русского: именные голоса CustomVoice — китайские/английские/японские/
корейские дикторы (serena, vivian, ryan, aiden…); русский они читают с
`language=Russian`, но акцент неизвестен — это и проверяем на слух. Варианты
русского голоса: клонирование своего (Base, 10–15 с записи, лицензионно чисто)
или VoiceDesign 1.7B по описанию.

Сборка в контейнере запрещена политикой безопасности сессии (сборка
скачанного кода) — не обходил. Вместо этого:
- `.github/workflows/qwen-spike.yml`: Windows-сборка закреплённого коммита с
  CPU (все варианты) + Vulkan, артефакт хранится 3 дня, с SHA256SUMS;
- `scripts/qwen/bench.ps1` + `bench-ru.txt`: скачивает закреплённые GGUF с
  проверкой SHA-256, для каждой модели и устройства запускает `tts-server`,
  озвучивает русскую новость (уже нормализованную правилами Глагола) голосами
  модели, печатает «секунд речи в секунду», сохраняет WAV для прослушивания.
Следующее: прогон CI, затем замер пользователем на ПК (RX 550), ПК сына
(GTX 1060) и ноутбуке (CPU). CUDA-сборка — только если Vulkan на 1060 окажется
медленным.
