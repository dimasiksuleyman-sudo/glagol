# Самообновление и версия программы (0.6.0)

Цель: Глагол показывает свою версию, проверяет обновления по кнопке и, по
желанию, при запуске; найденное обновление устанавливается из программы.
Основание: сообщение пользователя 2026-10-09 — «вариант 2, с переключателем
автопроверки и добавить версию программы».
В scope: tauri-plugin-updater (подпись minisign, latest.json в GitHub Release),
Rust-команды проверки/установки с прогрессом, раздел настроек, версия в UI,
скрипт latest.json, ранбук выпуска, оба руководства, CHANGELOG, выпуск 0.6.0.
Вне scope: подпись Authenticode, каналы beta, дельта-обновления, GL-006.

Решения:
- Автопроверка выключена по умолчанию: сеть только по явному выбору пользователя.
- Закрытый ключ создаёт и хранит пользователь; в репозиторий попадает только
  открытый ключ. Сборка с подписью — отдельный конфиг release, CI остаётся без ключа.
- Установка не начинается во время диктовки или локальной TTS-операции; перед
  установкой — подтверждение пользователя.
- TLS: rustls, как остальной сетевой код.

Критерии: гейты; 0.6.0 ставится вручную; выпуск 0.6.1 находится и
устанавливается из 0.6.0 на Windows пользователя (manual).
