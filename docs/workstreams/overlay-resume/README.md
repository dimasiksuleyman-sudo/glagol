# Таблетка диктовки после сна

Цель: после выхода Windows из сна (закрытие крышки ноутбука) таблетка диктовки
снова видна без перезапуска Глагола.
Основание: сообщение пользователя 2026-10-07 — таблетка исчезает после сна;
диктовка при этом вставляет текст, перезапуск приложения возвращает таблетку.
В scope: обнаружение выхода из сна и пересоздание скрытого overlay-окна.
Вне scope: другие окна, изменение вида таблетки, нативные power-хуки Windows.

Решения:
- Гипотеза: прозрачный WebView2 скрытого окна теряет отрисовку после сна
  (сброс GPU/compositor); перезапуск, то есть новое окно, это лечит.
- Сон определяется без unsafe и новых зависимостей: фоновый поток спит
  короткий интервал и сравнивает его с ходом системных часов. Во время сна
  потоки заморожены, поэтому скачок часов намного больше интервала означает
  пробуждение. Ложное срабатывание (перевод часов) лишь пересоздаёт окно.
- Окно пересоздаётся только вне сеанса диктовки, с новым label
  `overlay-N`: прежний label освобождается асинхронно после destroy.
  Capability и фронтенд принимают `overlay` и `overlay-*`.

Критерии: fmt, clippy, cargo test, tsc, build; manual на Windows-ноутбуке —
сон/пробуждение, затем таблетка видна при диктовке.
