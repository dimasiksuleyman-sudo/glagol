# Glagol 0.5.0 — English first

Пользователь утвердил реализацию полного плана 0.5.0. Результат — локальные изменения и проверенный компактный Windows x64 NSIS. Публикация, commit, push и обновление основной установки в задание не входят.

Языки интерфейса, диктовки и озвучки независимы. Первый запуск и первое обновление показывают English / Русский, затем две необязательные установки речи. Новая установка использует локальную диктовку; обновление сохраняет действующие и неявные настройки. Установщик выбирает язык Windows с английским резервным вариантом. Интерфейс переключается без перезапуска.

EN: Moonshine Small Streaming (нативный runtime v0.1.5, скрытый дочерний процесс того же EXE) и Silero v3_en. RU: существующие GigaAM и Silero v5.5. Для RU/EN TTS общий отдельно загружаемый Python/PyTorch runtime, модели устанавливаются независимо. Проверка целостности раз в 30 дней с досрочной перепроверкой по изменению файлов/ошибке worker. Push-to-talk сохраняется; промежуточного текста нет. Модели/runtime загружаются отдельно по выбору, проверяются по закреплённым размерам и SHA-256. При уже установленном исправном runtime Silero добавление второго языка загружает только недостающие файлы модели/зависимостей. Переключение языка само ничего не скачивает.

Полная локализация UI/Rust/трея/overlay; типизированные словари, SQLite-настройки, append-only миграция языка новых документов, совместимые старые библиотеки и бэкапы. Потоковый STT использует ограниченную очередь и потоковый ресемплер. TTS переиспользует последовательный pipeline временного WAV и библиотеки. Пользовательские материалы EN-first, внутренние ранбуки остаются русскими.

Этапы и обязательные проверки — в [state.json](state.json), фактические команды и результаты — в [log.md](log.md). Проверки включают миграцию, восемь сочетаний языков, локализацию, повреждения/отмены загрузок, streaming boundaries, crash/timeout/parent exit, RU-регрессии, TS/build, Rust fmt/clippy/test, NSIS. Недоступная ручная QA остаётся NOT_RUN/BLOCKED. Несовместимый выбранный runtime фиксируется блокером; автоматическая подмена движка не разрешена.

Прежняя серия verification-0.4.0 остаётся paused.
