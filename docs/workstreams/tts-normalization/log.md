## 2026-11-20T17:00:00.000Z — N1 выполнен

`src-tauri/src/text/normalize/`: `ru_numbers.rs` — количественные во всех
падежах и родах до 10^15, согласование существительных (миллион/миллиона/
миллионов, в косвенных — мн. ч.), порядковые (годы, даты, века; «тысяча
девятьсот…», «двухтысячный»), порядковые мн. ч. («девяностые»), десятичные
(«целая/целых», «десятая/десятых» — как прилагательные), «полтора/полторы/
полутора», «тысячу пятьсот» без «одну»; `ru.rs` — даты «20.11.2026» и «20 ноября
2026 г.», годы с «год/г./гг.», века римскими, время, «2-я/90-е/90-х/5-м»,
суммы с $/€/₽/руб./долл., %, тыс./млн/млрд/трлн, км, км/ч, кг, минус, группы
тысяч, коды с ведущими нулями по цифрам, падеж по предлогу/прилагательному/
глаголу перед числом («с» + творительный по следующему слову), род 1 и 2 по
окончанию следующего слова в нужном падеже, точка сокращения сохраняется в конце
предложения, идентификаторы (5G, A4, COVID-19) не трогаются, таблица
аббревиатур (IPO, SpaceX, США, ВВП…); `en.rs` — количественные, порядковые
(1st…), годы («twenty twenty-six», «two thousand five», «nineteen oh five»),
деньги $/€/£ с million/billion/bn/m/k (m/k только с валютой), проценты, десятичные
«point». Подключено в `preprocess` (RU) и `preprocess_english` (EN) — для любого
движка; num2words в воркере Silero остаётся страховкой.
Тесты: ≈ 80 случаев (вкл. новость пользователя дословно и корпус из 36
новостных оборотов) — меньше 200 из плана; таблица будет пополняться по ходу N2–N4.
Гейты: fmt --check, clippy --all-targets -D warnings, cargo test — 416 passed.
Документы: USER_GUIDE RU/EN (абзац о чтении чисел), CHANGELOG [Unreleased].
Не проверено: на слух в Silero на Windows (N4).
