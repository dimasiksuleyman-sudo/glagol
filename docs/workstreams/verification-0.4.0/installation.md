## Сценарий после выбора среды

Нужны два чистых Windows-профиля либо два исходных состояния VM. Отдельная папка
для EXE не изолирует `%LOCALAPPDATA%/app.glagol.desktop` и keyring service `Glagol`.
Не устанавливать 0.3.0 поверх рабочей пользовательской 0.4.0.
Windows Sandbox, VirtualBox и VMware в проверенных стандартных местах не найдены;
наличие VM в другом месте не исключено. Выбор среды запрошен у пользователя.
Computer Use на этом хосте возвращает native pipe unavailable, os error 2;
для визуальной QA нужен работающий UI-доступ или ручной прогон пользователем.

1. **Чистая установка:** в первом чистом профиле сверить SHA установщика 0.4.0,
   установить и запустить. Зафиксировать ОС, профиль, версию/путь EXE, ярлыки,
   иконку и single instance. Проверить пустую библиотеку, объяснение отдельных
   компонентов STT/TTS и отсутствие их загрузки без действия пользователя.
2. **Подготовка обновления:** во втором чистом профиле установить 0.3.0,
   восстановить синтетический ZIP через приложение. Проверить две записи,
   воспроизведение и экспорт обоих тонов. Записать настройки и SHA экспортов.
   Проверку ключей выполнять с отдельными тестовыми учётными данными; без них
   отметить её NOT_RUN, не сохранять секреты в evidence.
3. **Обновление:** полностью закрыть 0.3.0, установить 0.4.0 в том же тестовом
   профиле. Запустить, сверить версию EXE, две старые записи, воспроизведение,
   экспорт и SHA, настройки и сохранение тестовой конфигурации STT.
   Отдельно проверить, что Silero требует собственного согласия.
4. **Восстановление:** проверить UI-восстановление синтетической копии в тестовой
   0.4.0, наличие предварительного safety backup, записи и экспорт после
   перезапуска. При ошибке записать её и сохранить тестовые артефакты.
5. Записать результаты каждого сценария и ограничения сюда новой датированной
   записью. V2 закрывается после обязательного installation PASS; прослушивание
   Silero и живая диктовка продолжаются в V3/V4.

Команды генераторов создают новые каталоги и не предназначены для повторного
запуска поверх уже существующих файлов. Для нового прогона сначала выбрать новый
scratch-каталог; существующую приватную копию не удалять.
