## Выбранная среда

Ближайшую пользовательскую QA выполнять на **текущей установленной 0.4.0**:
Windows x64, EditionID Core, DisplayVersion 25H2, build 26200.9445.
Перезапуск/переустановка ради установления версии не требуется.

Перед любыми изменениями пользовательской библиотеки — штатная резервная копия
и проверка её пригодности. В V1 резервная копия не создавалась и не проверялась.
Не считать перенос EXE в другую папку изоляцией: данные разрешаются по app ID,
а служба Credential Manager в коде называется Glagol. Даже другой identifier
сам по себе не гарантирует отдельные ключи и отсутствие legacy cleanup.

Чистую установку и воспроизводимое обновление 0.3.0 → 0.4.0 проводить в отдельной
Windows VM/пользовательском профиле с тестовыми данными. Готовая такая среда
не установлена этим аудитом. WindowsSandbox.exe и vmconnect.exe по штатным
System32-путям отсутствуют; это не доказательство отсутствия всех сторонних VM.
Не устанавливать старую 0.3.0 поверх рабочей 0.4.0 ради теста обновления.
