не считать соответствующую проверку пройденной; согласованное сужение scope

сохраняются явно открытыми, если не вошли в согласованный набор fault injection.

## Ручной прогон на втором ПК

Пользователь выбрал десктоп с Windows 10 и потребовал по одному шагу с
подтверждением (2026-09-13). Для этой QA действует порядок: дать одно действие,
дождаться фактического результата, записать его и только затем дать следующее.
Не выдавать пакет действий на несколько тестов. С T22 пользователь изменил
протокол: давать одну проверку с ожидаемым результатом; «Го» подтверждает её
выполнение и совпадение результата (manual PASS), скриншоты больше не обязательны.
Это подтверждение только текущей проверки, не следующих пунктов.
При ошибке/неясности оставаться на текущем пункте, сохраняя исходный результат.
Запись результатов в локальном ранбуке выполняется после каждого ответа.

Текущий пункт и история: [windows10-manual.md](windows10-manual.md).
