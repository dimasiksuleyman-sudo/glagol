# Интерфейс без «простыни» и интерактивная справка (0.6.5)

Цель: экраны Глагола компактны и сгруппированы по задачам; встроенная справка
показывает, как пользоваться функциями, и подсвечивает настоящие элементы.
Основание: сообщения пользователя 2026-11-10 — «пройти по интерфейсу… сделать
пункты меню, чтобы оно не было простынёй»; «если делаем для ру, то зеркально
такой же будет и для англ.»; «сделать интерактивную справку… образец —
blood-p-tracker»; «Да, делаем всё, включая „знаете ли вы“».

Аудит (рендер с правдоподобными данными, 800 px ширины): «Настройки» ≈2700 px,
«Диктовка» ≈2300 px — сверху на «Диктовке» дублируется вся карточка движка из
настроек; озвучка в настройках начинается с лицензии и размеров; в библиотеке у
каждого документа полный плеер.

Решения:
- Настройки — вкладки с адресами /settings/dictation, /settings/speech,
  /settings/general, чтобы справка открывала нужную.
- «Диктовка» — ежедневное: состояние движка одной строкой со ссылкой в
  настройки, клавиша, микрофон, вставка, история. Карточка движка только в
  настройках; при ненастроенной локальной модели — карточка первой настройки.
- Редкое сворачивается в <details>: управление моделями, «Дополнительно»
  (потоки), «Компоненты и лицензия» Silero. Подсветка справки раскрывает
  свёрнутых предков цели.
- Библиотека: компактные строки и один общий плеер; поиск при длинном списке.
- Справка по образцу blood-p-tracker (src/pages/HelpPage.tsx,
  components/features/Coachmark.tsx, TipCard.tsx, lib/tours.ts, lib/tips.ts):
  темы с шагами и «Показать», подсветка по data-tour, карточка «Знаете ли вы?»
  (первый месяц раз в неделю, потом раз в месяц, только про неиспользованное,
  выключатель в справке). Состояние подсказок — localStorage (удобство
  пользователя, не данные).
- Тексты EN/RU парные; функции не меняются, только раскладка.
Вне scope: новые функции, смена дизайн-системы.
