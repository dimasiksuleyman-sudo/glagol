# Продвижение Глагола

Цель: о Глаголе узнают люди, которым он полезен (диктовка и озвучка на русском
без облака, сервер для офиса, живой голос Qwen3-TTS), а у проекта появляется
проверяемая репутация — она обязательна для заявки на бесплатную подпись кода
(SignPath Foundation, поле «Reputation», см. [code-signing](../code-signing/README.md)).

Решение 2026-11-21 (пользователь: «Согласен, заводи серию продвижения и готовь
0.7.0»): продвижение начинается **до** заявки в SignPath. Основание: в условиях
SignPath (signpath.org/terms) — «we cannot sign binaries based on source code
that nobody knows», числового порога нет, повторная подача не описана, а у
проекта на 2026-11-21 0 звёзд, 1 форк и 49 скачиваний установщика за все выпуски.
Плата: скачивания первой волны не копят репутацию SmartScreen для будущей
подписи — приемлемо, техническая аудитория проходит «Подробнее → Выполнить».
Запасной путь подписи — Certum Open Source (~69 €, проверка личности вместо
популярности).

## Шаги

- **PR1. Выпуск 0.7.0** — всё накопленное с 0.6.6: Qwen3-TTS, сервер для других
  компьютеров, Ctrl+Win, чтение чисел, словарь, ИИ-нормализация, скобки, выбор и
  проверка модели сервера, вставка в новый Outlook, справка. Версия, CHANGELOG,
  заметки RU/EN, сборка, подпись обновления, публикация (пользователь).
- **PR2. Витрина README** — скриншоты 0.7.0 (озвучка с Qwen и манерой чтения,
  сервер, справка), короткое «зачем Глагол», раздел «Почему SmartScreen
  предупреждает и как установить», ссылка на политику подписи.
- **PR3. Статья на Хабре** — черновик RU: зачем, как устроено (офлайн, сервер
  для офиса, Qwen vs Silero, нормализация чисел), цифры замеров (GTX 1060 /
  RX 550 / ноутбук), честные ограничения; публикует пользователь.
- **PR4. Каталоги и сообщества** — AlternativeTo (альтернатива Wispr Flow,
  Dragon, Windows Voice Typing), GitHub topics, профильные сообщества.
- **PR5. Заявка в SignPath** с собранными ссылками на репутацию
  (шаг C1 серии code-signing); при отказе — Certum.
