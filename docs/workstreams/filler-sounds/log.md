(RU: э+, э+м+, мм+, х+м+, аа+, ыы+ и дефисные «э-э», «м-м», «эм-м», «а-а», «хм-м»;
EN: uh, um, hm(m), mm, er, erm; не трогает «м», «а», «у», «мэм», «err»,

убирает висящую запятую в конце, сдвоенные тире и делает заглавной следующую
букву, если звук начинал предложение с заглавной. Конвейер применяет фильтр до
проверки на пустой текст (только звуки — ничего не вставляется). Настройка
`dictation_remove_fillers` (по умолчанию true; неизвестное значение — громкий
откат к умолчанию), переключатель на странице «Диктовка», EN/RU-строки,
сообщение валидации в messages.json. Руководства RU/EN, README (обе части),
CHANGELOG [Unreleased]. Версия не менялась (0.6.6 на ветке; отличие сборки —
