# Чистка звуков-заминок в диктовке

Цель: когда человек думает вслух («эм-м», «э-э», «м-м», «хм»), эти звуки не
должны попадать во вставленный текст.
Основание: вопрос пользователя 2026-11-13 — «Как им можно чистить звуки
паразиты, типа эм-м....», уточнение: «это я когда думаю, говорю: „Эм-м“. И
подобные. Можно даже в Интернете глянуть, словарь паразитов».

Решение:
1. Локальный фильтр текста после распознавания и до вставки — для всех
   способов распознавания (GigaAM, Moonshine, облако); без сети и без заметной
   задержки. Удаляются только отдельные слова-звуки, а не слова языка.
2. Набор (по лингвистике хезитаций: заполненные паузы — э-э, эм, м-м,
   растянутые гласные и сонорные; в английском — uh, um, er, erm, hmm):
   RU — э, ээ, э-э, эм, эмм, эм-м, мм, ммм, м-м, хм, хмм, аа, а-а, ыы;
   EN — uh, uhh, um, umm, er, err, erm, hm, hmm, mm. Одиночные «м», «а», «у»
   не трогаются (единица измерения, союз, предлог).
3. Словесные паразиты («ну», «вот», «типа», «как бы», «это самое»,
   «знаешь») не удаляются: это настоящие слова, без понимания смысла их
   не отличить («вот документ», «типа данных»).
4. После удаления поправляются пробелы, запятые, конец предложения и
   заглавная буква. Если в диктовке были только звуки — ничего не вставляется.
5. Настройка «Убирать звуки-заминки» в «Настройки» → «Диктовка», по
   умолчанию включена; история диктовок получает уже очищенный текст.

Вне scope: языковая модель для редактирования, удаление словесных
паразитов, пользовательский словарь.
