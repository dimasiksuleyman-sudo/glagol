# Проверка быстрого запуска Silero

Цель: на одном Windows-компьютере сравнить опубликованную Glagol 0.4.0 и
локальную сборку с фоновой проверкой/прогревом, подтвердить безопасность данных,
фактическую задержку первой и повторной озвучки и жизненный цикл worker.

Основание: пользователь 2026-09-15 ответил «го» на пошаговый A/B-план.

В scope: идентификация среды и артефактов, резервная копия библиотеки, холодный
baseline опубликованной версии, прямой запуск локального release EXE без
установки, повторные замеры, проверка отсутствия скачивания/распаковки, фоновой
работы, диктовки и 15-минутной выгрузки. Вне scope: публикация, установка NSIS,
изменение пользовательских файлов вне штатного бэкапа и искусственная порча
рабочего runtime.

Для синтеза используется только публичный короткий текст. В evidence не писать
тексты/аудио пользователя, ключи или содержимое библиотеки. Автоматические тесты
предыдущей серии не заменяют фактическую GUI-проверку.

Критерии: одинаковый сценарий и компьютер для baseline/candidate; автоматические
времена запуска, первой и повторной озвучки без ручного секундомера; фоновые лог-события candidate;
наблюдаемая выгрузка worker; отсутствие регрессии диктовки; явное решение о
готовности к commit либо checkpoint с дефектом.

Статусы находятся только в state.json; результаты добавляются в log.md.
