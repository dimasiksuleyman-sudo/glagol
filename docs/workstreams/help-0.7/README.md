# Встроенная справка к 0.7.0

Цель: страница «Справка» в Глаголе описывает все функции, появившиеся после
0.6.6, по тому же образцу, что и существующие 12 тем: короткие шаги RU/EN,
подсказка, совет и кнопка «Показать», которая открывает нужный экран и
подсвечивает настоящий элемент. Основание: просьба пользователя 2026-11-20
(«обязательно обновить интерактивную справку внутри самого Глагола»), пункт в
[очереди](../../roadmap.md); правило в [AGENTS.md](../../AGENTS.md).

Серия идёт параллельно tts-qwen: другой агент, своя ветка от `main`.

## Как устроена справка

- `src/lib/tours.ts` — список тем `TOURS`: `id`, экран (`route`), подсвечиваемый
  элемент (`target` = значение атрибута `data-tour`), запасной элемент
  (`fallback`), `needsTts` для тем озвучки, ключи текстов `title/steps/hint/tip`.
- `src/pages/Help.tsx` — страница; тексты — в `src/i18n/en.ts` и `src/i18n/ru.ts`
  (ключи `help…Title/Steps/Hint/Tip`; шаги — строки через `\n`).
- Подсветка находит элемент по `data-tour="<target>"`. Уже есть маркеры:
  `fillers`, `lan-server`, `lan-connect`, `recommendation` и др.
  (`grep -rn 'data-tour=' src`).

## Новые темы (P1)

| Тема | Экран | Элемент | Маркер |
|---|---|---|---|
| Звуки-заминки («эм», «э-э») | /dictation | переключатель удаления | `fillers` — есть |
| Диктовка по Ctrl+Win | /dictation | переключатель Ctrl+Win | добавить |
| Сервер для других компьютеров (хост) | /settings/dictation | раздел сервера | `lan-server` — есть |
| Подключение по коду (клиент) | /settings/dictation | «Вставить код подключения» | `lan-connect` — есть |
| Словарь произношения | /settings/speech | карточка словаря (`PronunciationSection`) | добавить, `needsTts` |
| «Как прочитается» | /synthesize | кнопка предпросмотра | добавить, `needsTts` |
| Улучшенное чтение чисел через ИИ | /settings/speech | карточка ИИ (`AiNormalizationSection`) | добавить, `needsTts` |

Тексты — по [USER_GUIDE.ru.md](../../USER_GUIDE.ru.md) и
[USER_GUIDE.en.md](../../USER_GUIDE.en.md), коротко и простым языком; пары
RU/EN говорят одно и то же. ИИ-тема обязательно упоминает, что функция
выключена по умолчанию и отправляет только короткие фрагменты.
