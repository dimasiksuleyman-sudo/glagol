# Подпись установщика Windows (Authenticode)

Цель — показывать проверяемого издателя установщика Windows и проверить,
сокращает ли подпись число предупреждений SmartScreen у новых пользователей.
Основание: пользователь 2026-11-19 попросил промпт для побочного исследования
«самый быстрый путь к бесплатному сертификату» и принёс результат; задача
четвёртая в [очереди](../../roadmap.md).

## Варианты из исходного исследования

| Вариант | Цена | Для частного лица из РФ | Заметки |
|---|---|---|---|
| SignPath Foundation | бесплатно для принятых OSS-проектов | уточнить у Foundation | сертификат на имя «SignPath Foundation», ключ в HSM, есть интеграция GitHub Actions, срок рассмотрения не подтверждён |
| Certum Open Source Code Signing | ~69 € | KYC, смарт-карта и ридер (доставка) | сертификат на имя разработчика; запасной вариант |
| Azure Artifact Signing (Trusted Signing) | ~$9,99/мес | физлица только США/Канада | облачный HSM |
| OV/EV коммерческих ЦС | $150–400+/год | KYC, аппаратный токен | EV больше не обходит SmartScreen сразу |
| Microsoft Store / MSIX | бесплатно | по сообщениям, верификация из РФ блокируется | MSIX переподписывает Microsoft |

В исходном исследовании нет ссылок на источники, даты проверки расходятся.
По SignPath см. проверку C1 в [журнале](log.md). Цены и региональные ограничения
других вариантов относятся к исходному исследованию и требуют проверки,
если к ним вернёмся.

Кандидат — **SignPath Foundation**. [Черновик заявки](application.md).

## План подписи и открытые вопросы

1. **Порядок подписей.** Подпись обновлений Tauri (minisign, `.sig` в
   `latest.json`, ключ 82D55017631804B2 с паролем) считается по байтам файла,
   а Authenticode и его метка времени меняют EXE. План C3 — получить конечный
   файл от SignPath, затем локально выполнить `pnpm tauri signer sign` над
   этим файлом и выполнить `pnpm release:assets`. После этого публикуются
   те же байты EXE. Закрытый ключ Tauri остаётся у сопровождающего. В C4
   проверить обе подписи и обновление на Windows со старой версии.
   [Tauri Updater](https://v2.tauri.app/plugin/updater/#signing-updates) ·
   [Ранбук выпуска](../../runbooks/release.md#подпись-обновлений-с-060).
2. **Сборка выпуска переезжает в CI.** SignPath может подписывать артефакт, собранный
   GitHub Actions из публичного репозитория (проверка происхождения). Сейчас
   установщик выпуска собирается на ПК пользователя
   ([ранбук](../../runbooks/release.md)); CI «Quality gates (Windows)» уже
   собирает NSIS для проверки. Загрузка релизного артефакта — C2.
   [Интеграция с GitHub Actions](https://docs.signpath.io/trusted-build-systems/github).
3. **Что именно подписывается.** В заявке — только внешний NSIS EXE. SignPath
   документирует Authenticode для PE-файла и вложенную подпись для MSI.
   В справочнике PE не поддерживает вложения, отдельного формата NSIS нет.
   Подпись внешнего EXE сама по себе не подписывает установленный
   `glagol.exe`. Если потребуется подпись `glagol.exe`, уточнить у Foundation,
   допускает ли OSS-процесс подпись отдельного CI-артефакта до сборки NSIS.
   Поддержка такого процесса для Глагола пока не подтверждена.
   [Форматы артефактов](https://docs.signpath.io/artifact-configuration/reference) ·
   [Пример вложенной подписи MSI](https://docs.signpath.io/artifact-configuration/syntax#deep-signing).
4. **SmartScreen.** Подпись позволит проверить издателя. Влияние на предупреждения
   и перенос репутации между проектами Foundation остаются открытыми. В C4
   проверить скачанный файл на чистой Windows.
5. **Условия SignPath.** Нужны OSI-лицензия, политика на главной странице и
   страницах скачивания, роли, MFA и ручное одобрение каждого выпуска.
   Веса Silero под CC BY-NC-SA 4.0 скачиваются отдельно. Попросить Foundation
   оценить этот случай. [Условия Foundation](https://signpath.org/terms.html).
6. **Метка времени.** Для файловой подписи SignPath управляет метками времени
   автоматически. Формат (в частности RFC 3161), TSA и цепочку доверия
   проверить на первом подписанном NSIS в C3/C4 через
   `signtool verify /pa /v /tw`. Токен SignPath для C3 — в GitHub Secrets.
   [Документация SignPath о метках времени](https://docs.signpath.io/crypto-providers/#timestamps).

Запасной путь — Certum OSS, если SignPath откажет.
