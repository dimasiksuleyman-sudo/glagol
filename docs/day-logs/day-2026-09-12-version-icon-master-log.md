# Glagol — 2026-09-12 — версия и варианты иконки

Пользователь подтвердил, что GigaAM v3 CTC распознаёт мгновенно, и обратил
внимание на незакоммиченные изменения и оставшуюся версию 0.2.1.

Версия исходников синхронизирована на 0.3.0 в package.json (ранее 0.1.0),
Tauri, Cargo.toml и записи приложения Cargo.lock. CHANGELOG получил секцию 0.3.0.
Добавлена проверка совпадения версий перед pnpm build / Tauri build;
порядок обновления версии записан в PROJECT_STRUCTURE.md.
Публикация релиза, тег и PR не создаются. Установленная копия не обновлялась.

Проверка версии, TypeScript и Vite build прошли напрямую через Node.
Глобальный pnpm 12.4.1 при вызове build попытался переустановить зависимости
и получил отказ в доступе к node_modules/.pnpm; использованы уже установленные
tsc и Vite. Нативный код с предыдущей проверки не менялся: 364 теста прошли,
обе модели проверены отдельным native smoke test. Установщик 0.3.0 пока не собран.

Встроенным image_gen сгенерированы четыре независимых концепта иконки:
синяя «Г» со звуковыми волнами, зелёное речевое облако, оранжевый микрофон,
фиолетовый переход текста в голос. Предпросмотры и точные промпты сохранены
в .scratch/icon-concepts/. Выбор остаётся за пользователем; иконки приложения
и трея на этом этапе не заменены.
