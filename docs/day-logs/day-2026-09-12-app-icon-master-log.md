# Glagol — 2026-09-12 — выбранная иконка приложения

Пользователь выбрал третий сгенерированный вариант: белый микрофон на
красно-оранжевом фоне. Использован именно выбранный PNG без новой генерации.
Исходник и точный промпт сохранены в docs/branding/; экспорт воспроизводится
штатной командой Tauri CLI icon. Иконки остаются частью версии 0.3.0,
которая ещё не публиковалась как релиз.

Заменены desktop PNG, ICO, ICNS и Windows Store-размеры в src-tauri/icons/.
Idle-значок трея и favicon также используют выбранный дизайн. Отдельный
круглый красный индикатор записи сохранён, чтобы состояния отличались.
Убраны стандартные заголовок Tauri и ссылка на favicon Vite; имя окна — «Глагол».
Для NSIS явно указаны installerIcon и uninstallerIcon: автоматического
наследования иконки приложения у этих полей нет. Обновлены RU/EN руководства,
CHANGELOG и комментарий к иконкам трея.

## Проверка

- Визуально проверены оригинал, 128×128 и 32×32; микрофон различим.
- ICO содержит 16, 24, 32, 48, 64 и 256 px. У PNG прозрачные углы (alpha=0).
- Проверка согласованности версии, TypeScript и Vite build проходят.
- Windows release EXE собран с FileVersion/ProductVersion 0.3.0;
  иконка извлечена средствами Windows из EXE и визуально проверена.
- Финальный NSIS собран после явного указания иконок установщика и удаления.
  `Glagol_0.3.0_x64-setup.exe`: 9 109 150 байт. Иконка из самого установщика
  также извлечена средствами Windows и визуально проверена.
  Автоматические тесты распознавания повторно не запускались: код поведения
  не менялся; предыдущий результат — 364 passed и отдельная проверка моделей.

Для сборки использован локальный override beforeBuildCommand с теми же
check-version, tsc и Vite через Node: установленный глобально pnpm 12.4.1
пытается переустановить node_modules и получает отказ доступа. Исходная
конфигурация проекта продолжает использовать pnpm. Pdfium взят из существующего
resources/pdfium.dll через PDFIUM_LIBRARY_PATH. Обходы не входят в установщик.

Изменения сохраняются локальным коммитом без PR, push или публикации релиза.
Установленное приложение не заменялось; проверка ярлыка и трея после установки
остаётся ручной проверкой пользователя.
