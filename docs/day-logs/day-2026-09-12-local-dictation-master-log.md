# Glagol — 2026-09-12 — локальные модели и сервер организации

## Согласованный объём

Пользователь разрешил реализацию загружаемых моделей русской диктовки и отдельно
потребовал сохранить сервер организации для многих офисных компьютеров.
Работа выполнена в `codex/local-dictation-models` от `3502422`.
PR, push, публикация релиза и установка на место пользовательской версии не выполнялись.

## Реализация

- Три режима: «На этом компьютере», «Сервер организации», «Облачный сервис».
  У каждого сохраняются настройки; сервер и облако имеют отдельные ключи в
  Windows Credential Manager, привязанные к адресу сервиса. Старый профиль совместим.
- Локальные GigaAM v3 E2E CTC и RNNT в GGUF Q8_0: 272 151 136 и 273 724 832 байта.
  Нативный transcribe.cpp 0.2.3 загружается отдельно: 20 077 848 байт.
  Python, фоновый локальный HTTP-сервер и GPU для этого режима не требуются.
- Фиксированный каталог с версиями, URL, размерами и SHA-256. Потоковая загрузка,
  прогресс, отмена, продолжение `.part` через Range, проверка целостности,
  проверка свободного места и безопасное извлечение архива. Удаление неактивных
  моделей, переключение, проверка и восстановление файлов выбранной модели.
- Модели хранятся в app-local `speech_models`, отдельно от установщика.
  Лицензия GigaAM сохраняется рядом; архив движка содержит лицензии зависимостей.
- Один экземпляр модели в памяти, сериализованный C ABI и `spawn_blocking`.
  DLL остаётся загруженной на срок процесса из-за глобального реестра ggml.
  Длинные записи делятся возле участков минимальной энергии между 16 и 24 с;
  все сэмплы сохраняются. Микрофон и запись на 60 с используют прежний pipeline.
- Офисный HTTP разрешён для явных частных IP и localhost; для DNS — HTTPS.
  Серверный режим не использует системный прокси без явной настройки пользователя.
  Redirect отключён. Во время локального распознавания сетевых запросов нет.
- Диагностические логи содержат ID модели и время операций, без аудио и текста.
- Обновлены обе версии USER_GUIDE, обе части README, CHANGELOG, SECURITY,
  PROJECT_STRUCTURE; добавлено описание нативного runtime и лицензия GigaAM.

## Проверки

Baseline: 353 unit-теста, 352 passed, 1 ignored. Добавлено 13 тестов:
12 обычных и один opt-in с настоящими моделями. Итого 366 тестов,
**364 passed, 2 ignored**, 0 failed; три doc-теста остаются ignored.
Проверены продолжение загрузки, сервер без Range, неверный диапазон,
повреждённый/слишком большой файл, отмена, профили, привязка ключей,
разрешённые адреса, пути архива, каталог и границы аудиофрагментов.

Отдельно успешно выполнен `native_gigaam_smoke` с обеими настоящими моделями
и официальным публичным русским `example.wav` GigaAM (~11,29 с).
Каждая модель распознала запись дважды. На Ryzen 7 7730U, CPU:
CTC — 821/911 мс, RNNT — 1448/1358 мс; загрузка с проверками в debug около 10 с.
Это измерение одного тестового файла, не обещание скорости или качества на любых записях.

Прошли cargo check, fmt, clippy --all-targets -D warnings, полный cargo test,
TypeScript --noEmit, pnpm build и production NSIS build.
Финальный установщик `Glagol_0.2.1_x64-setup.exe`: **9 013 837 байт**
(предыдущий 8 886 162; прирост 127 675 байт). Веса и runtime в него не входят.
JS 473,74 kB / gzip 148,04 kB; CSS 47,25 kB / gzip 8,86 kB.
Сборка использует существующую `src-tauri/resources/pdfium.dll` через
PDFIUM_LIBRARY_PATH: сетевой fallback build.rs недоступен, PDF-код не менялся.
