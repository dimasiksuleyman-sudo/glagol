# Руководство пользователя — Глагол

Глагол превращает длинные русские тексты в аудио. Вставляете текст или загружаете файл — получаете озвучку профессиональным голосом, которую можно слушать где угодно: на прогулке, в дороге, за домашними делами.

Создан для тех, кто предпочитает слушать, а не читать с экрана. Если вы любите аудиокниги, но хотите слушать *свои* документы — статьи, договоры, книги в PDF — Глагол для этого и сделан.

---

## Установка

1. Скачайте установщик `Glagol_<версия>_x64-setup.exe` со [страницы релизов](../../releases).
2. Запустите установщик.
3. Windows покажет предупреждение SmartScreen («Windows защитила ваш компьютер»). Это нормально для новых приложений без коммерческого сертификата подписи. Нажмите **«Подробнее»** → **«Выполнить в любом случае»**.
4. Готово — Глагол запустится автоматически.

Иконка Глагола — белый микрофон на красно-оранжевом фоне. Она используется
для приложения, ярлыка и значка в трее в покое; во время записи значок трея
меняется на круглый красный индикатор с микрофоном.

**Что нужно:**
- Windows 10 или 11 (64-бит)
- Для Silero дополнительно 1,9 ГБ свободного места
- Интернет для скачивания компонентов; для локальной работы после загрузки не нужен

## Локальная озвучка Silero (необязательно)

Silero TTS v5.5 — **для некоммерческого использования**, CC BY-NC-SA 4.0,
Silero Team. Для диктовки и офисного сервера компонент не нужен. MIT-лицензия
Глагола и условия выбранного STT-провайдера действуют отдельно.

1. Настройки → «Локальная озвучка — Silero v5.5».
2. Прочитайте полную лицензию и подтвердите некоммерческое использование.
3. «Скачать и включить»: модель 145,4 МБ + движок 249,3 МБ. Нужно 1,9 ГБ свободного места.
4. После установки выберите голос и нажмите «Послушать голос».

Python, pip и CUDA устанавливать самостоятельно не нужно. Загрузка происходит
только по вашему выбору; после неё синтез работает офлайн. При недоступности
сервера используйте «Выбрать скачанную модель» с точным `v5_5_ru.pt`.
«Продолжить загрузку» использует сохранённые части; «Проверить и восстановить»
переустанавливает проверенные компоненты; удаление освобождает место и сбрасывает
подтверждение Silero, сохраняя библиотеку и диктовку.

Для коммерческой озвучки позднее планируется Yandex SpeechKit v3. В 0.4.0
его ещё нет. SaluteSpeech и его ключ больше не используются.

## Первая озвучка

1. Откройте **Озвучить**.
2. Вставьте текст в поле — или нажмите **«Выбрать файл»** и загрузите документ.
3. Выберите голос.
4. Нажмите **«Озвучить и сохранить в библиотеку»**.

Через несколько секунд готовая озвучка появится в Библиотеке.

Во время синтеза доступна кнопка «Отменить озвучку». Числа переводятся в слова, неизвестная латиница читается по буквам; даты могут читаться по компонентам.

**Поддерживаемые форматы файлов:** `.txt`, `.md`, `.docx`, `.pdf`.

**Голоса (5):** Айдар, Бая, Ксения, Xenia, Евгений. У каждого своя манера — попробуйте разные, выберите тот, что приятнее слушать.

**Язык:** Глагол сделан для **русского текста**. Латиница и другие языки озвучиваются «на любителя».

**Объём:** комфортно озвучивает несколько тысяч символов за раз. Большие документы (книги, длинные PDF) обрабатываются целиком — текст автоматически разбивается на части.

## Диктовка (голосовой ввод)

Глагол умеет и обратное — превращать вашу речь в текст и вставлять его в любое приложение. Удерживайте горячую клавишу, дождитесь готовности микрофона, говорите, отпустите — распознанный текст появится там, где стоит курсор.

При нажатии пилюля сначала показывает **«Подготовка микрофона…»**. Начинайте говорить, когда появятся **красная точка и полоски уровня звука**: это означает, что от микрофона уже поступают данные. На некоторых устройствах Windows 11 подготовка может занимать около секунды. Речь до готовности микрофона не записывается. Если отпустить клавишу во время подготовки, попытка отменится без распознавания. Микрофон открывается для каждой диктовки и освобождается после её завершения; между диктовками захват не ведётся.

Настраивается всё на странице **Диктовка**:

- **Режим вставки** — «Автовставка» (текст вставляется сам, Ctrl+V) или «Только буфер обмена» (текст кладётся в буфер, вставляете вручную).
- **Горячая клавиша** — по умолчанию `Ctrl+Shift+Space`. Нажмите **«Изменить»** и физически нажмите нужную комбинацию (или введите её вручную, если она не распозналась). Если комбинация занята другим приложением, прежняя останется активной.
- **Микрофон** — «Системный по умолчанию» или конкретное устройство.
- **История** — по умолчанию **выключена**. Включите, чтобы Глагол сохранял до 10 последних расшифровок (кнопка «Копировать» вернёт текст в буфер, чтобы перевставить сказанное ранее). Выключение останавливает запись новых строк, но накопленное остаётся видимым до кнопки «Очистить историю».
- **Надиктовано всего** — счётчик минут за всё время.

В **Настройки → Диктовка** выберите, где распознавать речь:

- **На этом компьютере.** Выберите GigaAM v3 CTC или RNNT и нажмите «Скачать и использовать». Обе модели распознают русский с пунктуацией. Модель занимает около 272–274 МБ; один общий движок — ещё 20 МБ загрузки. Освободите не менее 500 МБ. Прогресс виден в настройках; загрузку можно отменить и затем продолжить. После проверки файлов модель готова к диктовке без интернета. Python и отдельный сервер устанавливать не нужно. Этот режим пока поддерживается на Windows x64 и использует CPU.
- **Сервер организации.** Укажите адрес общего сервера, например `http://192.168.1.10:8000/v1`, имя модели на нём и API-ключ, если он требуется. Подходит и `http://localhost:8000/v1`. Сервер должен поддерживать OpenAI-совместимое распознавание `/audio/transcriptions`; `/models` необязателен. Один сервер может обслуживать много рабочих мест, без скачивания моделей на каждое. Сам сервер устанавливает администратор организации. HTTP разрешён для localhost и частных IP; он передаёт голос и ключ без шифрования, поэтому используйте его только в доверенной сети. Для доменного имени нужен HTTPS с доверенным сертификатом. Системный прокси в этом режиме не применяется; при необходимости задайте прокси явно.
- **Облачный сервис.** Выберите провайдера или введите свой адрес, модель и ключ. Можно указать прокси только для распознавания, без системного VPN.

Настройки и ключи сервера и облака хранятся раздельно. Изменение режима в списке открывает настройки; режим включается кнопкой «Сохранить и использовать» либо «Скачать и использовать». При смене адреса старый ключ не отправляется новому сервису — введите соответствующий ключ заново.

Скачанные модели хранятся в `%LOCALAPPDATA%\app.glagol.desktop\speech_models`, отдельно от установщика и аудиобиблиотеки, и сохраняются при обновлении приложения. Загрузка идёт с GitHub и Hugging Face с проверкой размера и SHA-256; при локальной диктовке сетевых запросов нет. Неиспользуемую модель можно удалить в настройках; чтобы удалить активную, сначала выберите другую модель или режим. Кнопка «Проверить файлы и восстановить» восстанавливает повреждённую загрузку. Пакет движка остаётся общим для моделей.

Модель загружается в память при выборе или первой диктовке после запуска. Длинные записи разбиваются на участки до 24 секунд около тихих мест; на границах возможны ошибки пунктуации и редких слов. Иностранные термины стоит проверять вручную.

### Известные ограничения

Диктовка работает поверх Windows, у которой есть свои правила. Вот что стоит знать заранее.

1. **Не-текстовый буфер обмена теряется.** В режиме автовставки Глагол на миг подменяет буфер обмена расшифровкой, а потом восстанавливает прежнее содержимое. Если там была картинка или файлы (не текст), восстановить их не получится — они пропадут из буфера.
2. **Менеджеры буфера обмена, меняющие переносы строк.** Некоторые менеджеры буфера «нормализуют» текст (заменяют переносы строк). Из-за этого Глагол считает, что буфер изменился кто-то другой, и не восстанавливает прежнее содержимое — из осторожности.
3. **Окна, запущенные от администратора.** Если активное окно запущено с повышенными правами (от администратора), а Глагол — нет, горячая клавиша до него не дойдёт, и надиктовать в такое окно не выйдет. Запустите Глагол от администратора, если это нужно постоянно.
4. **Шумная обстановка.** Порог тишины — абсолютный. В тихой комнате он отсекает молчание и пропускает речь. В шумном месте (кафе, машина) фоновый гул может пройти фильтр, и распознавание выдаст лишний текст. Диктуйте в относительной тишине.
5. **Два одинаковых микрофона.** Если к системе подключены два устройства с одинаковым названием, Глагол не сможет их различить в списке — выбор может указывать не на то, что вы ждёте.
6. **Win+V и журнал буфера обмена.** Если у вас включён журнал буфера обмена Windows (`Win+V`), каждая расшифровка попадёт в его историю. Отключить можно в Параметрах Windows → Буфер обмена.
7. **Конфликт `Ctrl+Shift+Space` в Office.** В Microsoft Office эта комбинация вставляет неразрывный пробел. Если диктуете в Office, назначьте другую горячую клавишу (например `Alt+Shift+D`) на странице Диктовка.

**Совет по отправке логов:** перед тем как приложить логи к сообщению об ошибке, **полностью закройте Глагол** — при выходе он дописывает в лог-файл всё, что оставалось в буфере. Иначе последние строки могут не попасть в файл.

## Резервное копирование и перенос

Глагол умеет сохранять всю библиотеку (документы + аудиофайлы) в один архив — удобно для бэкапа или переноса на другой компьютер.

**Создать копию:**
Настройки → **«Создать резервную копию»** → выберите папку. Получится один `.zip`-файл со всем содержимым.

**Восстановить / перенести на новый компьютер:**
1. На новом компьютере установите Глагол. Для новой озвучки отдельно включите Silero с подтверждением её условий; для прослушивания старых WAV она не нужна.
2. Настройки → **«Восстановить из резервной копии»** → выберите ваш `.zip`.
3. Глагол покажет, что заменит, и попросит подтверждение.
4. После восстановления приложение перезапустится — вся библиотека на месте.

Перед восстановлением Глагол автоматически создаёт резервную копию текущего состояния — на случай, если что-то пойдёт не так.

## Если что-то не работает

**Озвучка не запускается**
Проверьте установку Silero и подтверждение условий в настройках. При повреждении файлов нажмите «Проверить и восстановить». При сетевой ошибке можно выбрать скачанный `v5_5_ru.pt`.

**Установщик не запускается — предупреждение Windows**
Это SmartScreen. «Подробнее» → «Выполнить в любом случае». Подробнее в разделе «Установка».

**Голос звучит непривычно**
Попробуйте другой голос из пяти — у каждого своя манера. Если озвучиваете не русский текст — это не сработает, Глагол только для русского.
